# Media Gen Skill 1.4.0 · Direct ComfyUI operation

允许 Skill 使用者/Agent 按用户任务直接操作获准设备的原生 ComfyUI：查看节点和模型、编辑 API 格式 Workflow、设置图参数、上传图片/视频/音频/3D 输入、提交并查询队列/历史、下载实际文件和管理个人 Workflow。Admin 需先对 Key 独立启用原生面板并选择设备。原有已发布模型的业务调用继续支持。

Allows Skill users and agents to directly operate explicitly authorized ComfyUI devices for the user's task. Discover nodes/models, edit API-format graphs, upload media/meshes, submit, inspect owned queues/history, download file outputs and manage personal workflows. Admin must enable native access and grant devices separately. Existing published-model business calls remain supported.

新增 Python 3.10+ 标准库客户端 `comfy_origin.py`，包括派生 Cookie/CSRF 会话、设备独占、实际遮罩上传、请求前持久意图、未知回执恢复、轮询心跳、文件归属及安全归还。单文件内嵌业务/原生两份参考及两个完整客户端。会话文件含凭据，状态文件可能含提示词，均不得提交或公开。

Adds a standard-library native client with derived sessions, exclusive reservation, mask protocol, durable submission intent, exact-intent recovery, polling heartbeat, owned downloads and safe return. The standalone Skill embeds both references and both complete clients. Keep session credentials and private request state outside Git and installations.

原生 Workflow 不受公开模型别名或冻结参数限制，但只使用设备已安装的节点/模型；自定义节点具备主机权限，仅供可信操作者。源文件留在设备，不自动上传云端或执行八小时删除。下载报告本地 SHA-256，只有提供独立摘要才标记源摘要已校验。关闭页面、超时、退出或中断请求不能当作停止证明；不解开其他任务、维护或未知占用。

Native graphs use installed nodes/models independently of published aliases/presets. Custom nodes have host authority; this is trusted-operator access. Outputs stay on the device and do not inherit cloud eight-hour deletion. A local checksum is not independent source verification unless a known digest is supplied. Browser exit, timeout, logout and interruption requests do not prove execution stopped or permit force-unlocking.
