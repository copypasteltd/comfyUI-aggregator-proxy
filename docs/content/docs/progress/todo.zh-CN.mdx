# 待办

本项目是在已有开源画布上适配原聚合API。[当前范围](../../../studio/37-交付范围纠正与核心适配现状.md)替代历史46行评估作为工作清单。已实现能力列在[待测试](pending-test.zh-CN.mdx)，不再反复算入待开发。

## 已确认的核心开发项

本轮范围复核没有新增确认的核心功能缺项。连接/目录、发布表单、上传、异步任务、产物回填、本机项目、青柠明暗和八类案例已有实现。后续出现可复现的画布操作失败或错误请求，按具体缺陷记录和修复；更多组合未测试本身不证明缺少代码。

## 具体问题及外部依赖

| 事项 | 状态与责任 |
| --- | --- |
| 近期双参考视频 | 最近真实任务返回`preparation_transport_failure`；原API/设备准备链路恢复后再明确调用验证。继续展示失败，不修改转发、不自动新建替代任务 |
| 浏览器支持声明 | 已有本机Chromium/Firefox、公开站点Chromium证据；Windows WebKit Cookie/解码失败、实际Safari未验，不宣称支持。新增浏览器承诺时补对应验证 |
| 当前全模型执行 | 本次文档纠正未重新测试；目录可见和历史结果不能证明当前GPU可用 |
| 原API运维 | ComfyUI移交即删、设备均衡/容量、空闲内存策略和Admin管理属于原系统独立工作，不计画布开发量 |
