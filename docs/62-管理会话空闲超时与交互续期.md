# 62 · 管理会话空闲超时与交互续期

2026-10-24，第 62 增量。本地实现、数据库恢复、浏览器及精确候选安装验证通过；完整首版范围不变。

## 缺口与边界

现有管理会话只检查 expires_at，未落实空闲退出。新增持久 last_activity_at 和服务端空闲校验；Admin 的明确用户交互才续期，GET、自动刷新、SSE 校验、页面可见性和业务 Key 请求均不算交互。图片、视频、ComfyUI Workflow 音频及其任务、GPU、额度和结算不受会话生命周期改变。

沿用 GEN_SESSION_SECONDS 的绝对时长，实际默认 28,800 秒（8 小时），范围 60～86,400；不把旧设计的 12 小时初值写成已实现。新增 GEN_SESSION_IDLE_SECONDS，默认 1,800 秒，范围 60～86,400；有效截止始终为绝对时间和最后交互加空闲时长的较早者。空闲配置作用于后续鉴权；修改绝对时长只影响新登录，不延长已有会话的绝对截止。Cookie Max-Age 仍按原绝对时长签发；续期不换 Cookie、CSRF、身份或角色。

## 服务端与契约

新增 POST /admin/api/v1/session/activity，只有当前管理会话、正确 Origin 和 CSRF 可提交固定 `{ "activity": "interactive" }`。不接受客户时间、用户 ID、任意字段或 Bearer Key；无需新增管理权限。成功返回 lifetime；登录和 GET session 也返回可空的新增 lifetime 字段以兼容旧响应消费者。冻结形状在 contracts/admin-session.schema.json：absolute_expires_at、idle_expires_at、idle_timeout_seconds、server_time 均明确使用 Unix 秒或秒数。显示截止向上取整，服务端鉴权仍按原始微秒精度，响应不授予额外有效期。

普通鉴权始终只读，空闲截止相等时拒绝；GET session 与 SSE 的周期检查不延长 last_activity_at。活动写入只锁当前会话，锁后重新检查会话、用户启停/revision、pepper、秘密值、CSRF 和两个截止，不能复活已撤销或已到期会话，不能改绝对截止。并发活动单调推进，失败回滚；不为每次交互写管理审计或 outbox，避免自动流量膨胀。登录/退出原有审计和权限保持。

新增迁移 0a7d9b4e2136，前序 f96c8a3d1025，只添加可空 last_activity_at。历史 null 使用原 created_at 作保守基准，不伪造交互、不回填历史；已有会话可能需要重新登录。列已有活动数据时拒绝删除列降级，保留事实并向前修复。开发与测试库迁移前原生备份验证，实际恢复核对原完整行及新增列语义。

## 图形交互与资源

Admin 根组件统一监听可信的 pointerdown、keydown、wheel 交互，不读取输入值；不接受脚本合成事件。持续操作最多每 30 秒提交一次，有界合并且至多一个请求；无交互时不发送活动。服务器终止时间由响应与本机单调时钟计算，普通页面轮询不修改它。截止到达先只读复核服务器，其他标签页的真实活动可使当前页继续；服务器拒绝或到期无法确认时关闭敏感界面并提示重新登录。

隐藏、注销、会话失效、组件卸载时取消本次请求和计时器、丢弃待续期交互；恢复可见先只读复核，不能把恢复本身当作续期。旧请求不得覆盖注销或新登录状态。活动网络失败不伪造续期，保留已知截止；只有后续真实交互可重试。沿用现有 Admin 样式，不新增用户必须处理的技术配置步骤。
