# 26 · 告警与节点尝试只读查询约定

2026-10-23，设计基线 v0.4。补足已登记的三个只读接口，沿用现有身份和权限，不新增远程动作、状态转换或数据库迁移。本文只规定本次增量；完整监控、人工隔离和真实设备仍按原验收项处理。

## 告警快照

`GET /admin/api/v1/alerts` 要求管理会话与 `operations:read`。从 PostgreSQL 的同一个 REPEATABLE READ READ ONLY 快照派生告警，分页每页 50 条，返回 `snapshot_at`、`page`、`has_more` 和当前筛选总数；可按 `kind` 筛选。按严重级别、关联记录时间及稳定资源标识排序。ID 由规则和资源标识组成，重复读取不写入新事件。

| kind | 条件 | 严重度 / 关联记录时间 |
| --- | --- | --- |
| gpu_occupancy_uncertain | GPU 占用明确为 uncertain | critical / 获得占用时间 |
| job_reconciling | 任务处于 reconciling | warning / 受理时间 |
| node_heartbeat_stale | 启用节点最后心跳或创建时间早于快照 15 秒 | warning / 最后心跳或创建时间 |
| channel_observation_stale | 启用且未删除渠道的最后观测或创建时间早于快照 15 秒 | warning / 最后观测或创建时间 |
| channel_config_unverified | 启用且未删除渠道的应用或验证版本不等于期望版本 | warning / 渠道创建时间 |
| job_waiting_over_5m | queued 任务受理已满 300 秒 | warning / 受理时间 |
| operation_failed | 24 小时内 failed 或 partial_failed 管理操作 | warning / 操作创建时间 |
| gateway_settlement_unacked | 超过 300 秒仍未确认的 gateway.settlement outbox | warning / outbox 创建时间 |

所有阈值以本次服务端快照时间计算，边界包含等于。`recorded_at` 是上述关联记录的时间，不声称异常持续了同样时长。节点/渠道失联只提示未知，不表示 GPU 空闲；告警查询绝不释放资源。响应只含规则、严重度、关联 ID 和记录时间，不带配置秘密、客户请求、回执正文或账本载荷。

告警页显示快照时间、总数、筛选、分页、加载、空列表、失败和最后成功快照。页面可见时每 5 秒刷新；切换页面、隐藏或退出后终止本页请求并释放定时器。首次请求前不显示“无告警”。本次不提供虚构的确认/恢复按钮；条件消失后派生记录自然消失，操作失败规则则按 24 小时窗口保留。OOM、磁盘压力、错误趋势等尚无完整观测支持的规则仍待实现。

## 节点详情

`GET /admin/api/v1/nodes/{id}` 要求管理会话与 `nodes:read`。在一致只读快照返回节点基本信息、已登记 GPU，以及未删除渠道的安全投影，两个子列表分别限制 100 条并返回截断标识。不返回节点凭证、verifier、原始 inventory 或渠道明文/密文凭证。当前管理角色仍按现有全局角色授权，不伪称已有项目级管理范围。

## Worker 尝试状态

`GET /internal/v1/attempts/{id}` 要求独立 Worker 凭证，并必须提供查询参数 `boot_id`（UUID）与 `fencing_token`（正整数）。首先按认证节点和 attempt 查找；其他节点的 attempt 一律 404。当前节点 boot、attempt boot 或 fence 不符返回 409。新 boot 查询旧执行使用已有 reconciliation-context 流程，不能通过本接口恢复所有权。

返回协议版本、服务端时间、job/attempt 标识、权威任务状态与 revision、最后 journal_seq、是否当前 attempt、租约截止、取消意图、是否关闭、生成是否已释放、当前 attempt 是否仍占 GPU，以及是否需要核对。相同 boot/fence 可查询已关闭的历史尝试和已过期租约，但只读取这些事实，不续约、不重新授予提交权、不回传工作流、输入、渠道地址、凭证、prompt_id 或原始证据。GPU 上已有更高 fence 的新任务不会使旧任务仍有效的上传结果租约失效。

## 验证出口

真实隔离 PG/HTTP 测试检查规则时间边界、终态/删除/停用排除、筛选分页、一致安全投影、只读无副作用，以及 Worker 的跨节点、旧 boot、错 fence、过期和生成释放后的结果租约。界面使用真实本地 API 检查空列表和加载；合成异常数据只在隔离测试中构造。接口数量和合成告警不作为真实设备监控或人工故障处置验收。

[46](./46-生成失败归因与规格隔离.md) 增加 spec_isolation 派生告警，只由当前活动隔离行生成，并链接至图形规格隔离页面。告警无需展示提示词、私有图或权重；状态恢复后从当前告警快照移除，操作审计继续保留。
