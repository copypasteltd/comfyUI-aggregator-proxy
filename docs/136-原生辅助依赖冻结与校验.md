# 136 · 原生辅助依赖冻结与校验

状态：代码、候选预检及云端/3080 Worker 原生部署已完成；13 个受影响候选已创建新冻结版本，逐项生成批准仍在进行。补齐原生 3D 与音频节点调用 ComfyUI 目录外辅助程序时的依赖校验；不把平台的待完善项算作缺模型的源工作流阻塞。

| 编号 | 约束 | 实现与验收 |
| --- | --- | --- |
| NATIVE-01 | 根目录由设备运营者在本地配置；发布包只引用名称和相对文件，不指定绝对路径 | 每个本地渠道配置 `native_dependency_roots`；最多八个，名称唯一且受限。拒绝盘根、链接根、凭证/状态目录及 ComfyUI 客户输入输出区域 |
| NATIVE-02 | 冻结实际辅助代码、解释器和模型文件 | Workflow 1.3 的 `dependency_lock.native_roots` 声明名称及文件 SHA-256/字节数，合计最多 4096 个文件、单文件最多 1 TiB；路径无穿越、缓存、作业或私有配置，重复路径按 Windows 大小写规则拒绝 |
| NATIVE-03 | 无安装、下载或任意命令权限 | Worker 仅在白名单内逐块读取并计算摘要，不执行辅助程序，不返回原文件或绝对根路径；HTTP-only 渠道不接受本地依赖 |
| NATIVE-04 | 不支持新锁的旧 Worker 不能接单 | 增加 `native-dependency-roots-v1` 能力；工作流同步、管理指令领取、设备池、准入后调度、重试、任务领取和排队估计均按冻结锁筛选。同步成功回执还必须包含 `native_dependencies_verified=true`；仅声明普通环境成功不能激活绑定 |
| NATIVE-05 | 同步与实际执行都校验 | 未登记、缺失、变化、目录或链接逃逸均拒绝，环境摘要包含实际观察结果。批准仍须真实产物和当前设备/冻结版本，不以摘要替代生成验收 |
| NATIVE-06 | 已冻结发布不可覆盖 | 为受影响候选建立新冻结版本、保留旧版和操作记录；只更新临时试跑 Key 的对应测试范围，不扩大客户 Key |

本地配置示意：`native_dependency_roots: {"native_3d": "C:/dev/3d-generation"}`。发布包只记录 `name: native_3d`，及 `run_external.py`、实际使用的模型/源文件等相对文件的摘要；不能请求读取本地任意目录。该字段属于运营者冻结依赖，业务请求及模型 usage 不公开设备路径，也不能修改它。

Existing models remain compatible when the optional lock is absent. The new lock requires a separately advertised Worker feature and operator-configured roots. It does not authorize package installation, model downloads or shell execution. Hash verification runs at synchronization and execution; runtime generation and ordinary API download checks remain separate acceptance steps.

Windows/云端原生构建及安装已完成，真实生成批准与业务下载记录继续逐项补充；没有取得相应证明的候选继续保留草稿。所有开发遵守无本地 Docker/WSL 和原生进程约束。

## 本次实际盘点与草稿

3080 的只读哈希回执成功，四组共 3,567 个普通文件，无缺失或变化：原生 3D 307 个、播客运行代码 883 个、补充原生库 2,370 个、TTS 模型随附代码 7 个。清单保存在私有操作目录，不向仓库提交权重、辅助源码或设备路径。哈希程序没有启动模型、安装组件或下载文件；远程启动调用曾超时，后续独立读取已完成清单及摘要，未重复启动。

`app/scripts/workflow_catalog_native.py` 从已观察的清单生成全新目录中的候选：四个 TripoSG/PartCrafter 变体、五个使用补充原生库的 3D 变体和四个播客变体，共 13 个。原生 3D 仅选择目标模型及按需背景移除权重；不替换缺失模型。播客的外部程序和模型随附 Python 代码使用分别登记的根。保持原有别名、功能名称及旧冻结版本。原生库锁覆盖本次明确选择的辅助代码、二进制和包元数据，不能据此声称已冻结设备上全部 Python 安装。

新的 213 个候选均通过契约、公开用法和实际图编译检查：[候选预检](evidence/2026-11-04/native-dependencies-136-catalog-offline-second.json)。原始不完整草稿目录及失败报告保留；后续生成只使用成功的新目录。[本次目录快照](evidence/2026-11-04/workflow-catalog-133-online-second.json) 记录新增 7 个图像模型已完成平台验证、运行批准、正式发布及普通业务下载；13 个新依赖版本尚未取得这些运行证明。

## 图像交付尺寸复查

一个 Qwen 编辑候选真实生成了 1024×1024 PNG，但其封装按未使用的潜空间节点声明为 768×1376，平台按尺寸约束拒收。保留该失败记录并修正封装生成器：图片最终交付必须经过声明尺寸的确定性缩放节点，采用 Lanczos 与居中裁切，并公开说明交付尺寸和上游原生采样尺寸的区别。已有完全相同的最终缩放节点可复用，保留源图中同名节点，不允许覆盖或制造自循环。为受影响且未批准的候选创建新发布版本后重新试跑，不把封装错误计入源工作流阻塞，也不改写已冻结版本。
