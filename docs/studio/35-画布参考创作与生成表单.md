## 使用方式

1. 在连接页填写原 API 地址和管理员分配的业务 Key，读取模型及用法。需要刷新后恢复连接时，主动勾选在可信浏览器保存 Key。
2. 打开画布，选择希望参与生成的图片，再点击“新建创作”。所选图片按顺序填入当前模型公布的参考槽位，每个槽位显示实际图片缩略图和名称。
3. 检查模型、完整规格、创作描述和参考图用途。槽位可以改选任意现有画布图片、该连接已保存的参考图，也可以选择本机文件。单图输入、蒙版、首帧和多参考数组分别遵守模型 Schema，不互相代替。
4. 提交前先验证整份表单和全部参考原件。缺图、原件不可读、规格或描述不合法时不会先上传一部分远程素材，也不会创建生成任务。已经暂存到本机的原件仍保留。
5. 上传结果暂未确认时保留同一记录。明确再次提交会使用原上传幂等键和相同字节进行核对；已有有效 asset 不重复上传。生成请求受理后保留原任务 ID，由原服务异步调度。
6. 任务成功后点击“载入产物”。原件通过类型、长度与摘要核对后回到画布，并连接实际使用的参考节点。云端完成后保留八小时，本机副本单独保存；重要作品另存原件或导出完整 ZIP。

多张图片被选中不表示都会参与生成。模型只有一个源图槽位时仅填入一张；多余所选图片显示未加入输入的数量。用户更换参考图后，结果连线跟随实际输入，不能把无关的旧选择画成来源。切换模型时重新按其已发布槽位填入，提交前应检查缩略图及用途。

## 开发约束

- 架构保持[文档20](20-独立画布与既有API融合最终边界.md)的边界。无新生成后端、转发代理或队列，不改原 API、Worker、调度、数据库、Admin、配置及服务生命周期，也不让画布直连 ComfyUI。
- 业务参数只来自当前 Key 可发现的 `usage.request_schema`、完整 `presets`、参考 `slots` 和权限策略。规格不是任意宽高组合；平台未发布的 720×1080 或时长不能自行补出。
- 新创作若早于目录恢复，等真实目录到达后初始化一次。后续刷新只更新可用性与限制，不覆盖用户已经选择的模型、描述、规格和参考图；新身份不能继续旧身份提交。
- Schema 预检使用的临时素材 ID 只存在于本机验证步骤；发给原 API 的创建正文必须使用真实上传获得的 asset ID。全部输入可读不代表远程上传必然成功。
- 每张上传使用已有本机日志及原幂等键；任务仍采用既有“持久化原意图后提交”流程。上传未确认、任务提交未知、已知任务失败分别处理，不在不确定状态下新建替代任务。
- 结果按真实已用参考节点建立连线。普通文件上传没有画布节点时不虚构来源节点；已选择但未采用的图片不计入生成来源。
- 未新增产品超时、重试、上传上限、并发上限或保留期限。测试工具的观察窗口仅用于自动化验收，不能变成产品请求限制。
- 04·青柠原始 CSS、字体与令牌未修改。新增表单继续使用原组件系统；预览 URL、测试浏览器与临时 HTTP 服务在使用结束后释放。
