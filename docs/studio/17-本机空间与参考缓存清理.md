# 17 · 本机空间与参考缓存清理

对应F-01、F-15、F-20、F-27、F-32、F-35和F-43。入口为`/studio/storage`，从连接页或素材库进入；继续复用04·青柠样式。135.1的本机空间增量不改数据库版本；136.1的Key轮换单独升级至v4，见文档18。本页沿用已有三库，不新增生成队列、文件大小、保留时间或并发限制。

## 使用与统计

页面显示本机记录内容、浏览器提供的站点占用/配额，以及三个已有数据库的仓库分布。记录内容包含嵌套Blob和二进制，不解码媒体；数字是内容估算，不包含索引等数据库开销。站点占用来自浏览器StorageManager，包含该源其他存储，不等于磁盘可用空间；普通HTTP下浏览器未提供配额时明确显示未知，不附加HTTPS条件。只读统计不创建不存在的数据库，不升级或清空数据库。

总体占用可以包括同一浏览器其他连接的数据；参考缓存清单只显示当前源站与Key指纹对应的记录。切换连接后旧清单立即隐藏，晚到读取不能重新显示旧身份内容。页面不显示Key、幂等键或原任务正文。作品原件通过素材库管理，任务清单通过任务页另行备份。

## 手动清理参考缓存

1. 仅对已确认上传且回执的状态、SHA和长度与本机原件一致的记录开放清理。
2. 所有原任务都保护其参考图，包括prepared、submitting、unknown、accepted和terminal；递归检查原正文内的source_image、mask和多参考asset_id，不按当前表单或终态猜测引用。
3. 未确认/响应未知的上传、无法解析的当前身份原正文、未知版本/无身份任务及无法核对的回执均保留，不把缺少证据视为无引用。
4. 点击后先确认具体记录；确认执行时，在同一个严格IndexedDB读写事务中再次读取最新uploads/intents，核对原身份和所选记录快照。已变化、已新增引用或已切换连接则拒绝删除。
5. 删除只影响本机upload记录，不调用远程删除、不删除云端素材/任务/生成原件，不修改原正文或幂等键。正在编辑但尚未持久化的参考选择需要重新选择；清理不会代替用户重新上传或生成。
6. 上传回执采用条件更新；记录已被清理时晚到结果不能重新创建缓存，也不能用旧失败回执覆盖另一个页面已确认的上传。跨页广播刷新现有参考选择目录。

这不是上游ComfyUI输出移交清理（F-29），也不是普通image/file自动回收。普通图片、媒体和离线副本仍需跨数据库引用保护，当前继续保留；上传未确认缓存的处置、完整灾难恢复与真机配额行为继续跟踪。
