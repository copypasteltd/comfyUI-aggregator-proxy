# 128 · ComfyUI 三维模型产物与 3080 适配

日期：2026-10-29。状态：首条 TRELLIS2 GLB 路径已实现并部署；实际平台验证与独立业务交付通过。其他 3D 格式及完整产品验收仍开放。

## 1. 本次交付边界

以 3080 已有的 TRELLIS2 为实际接入例子，新增 `image_to_3d` 异步任务。实际图从 LoadImage、背景去除和三阶段采样，经形状/颜色解码，连接 PaintMesh、MeshToFile3D 和 Save3DAdvanced。TripoSG、PartCrafter 另依赖 ComfyUI 目录外的独立 Python/CUDA 环境，现有依赖锁不足以验证该环境，本次不发布这两条路径；Pixal3D 留待单独验证。不得把节点存在或画布完整写成运行通过。

首批交付单个自包含 GLB 2.0，规范 MIME 为 `model/gltf-binary`，每任务一个主产物，最大 512 MiB。OBJ/MTL/贴图、多文件 glTF、FBX、STL、USDZ、点云与压缩几何暂不在此适配器内；后续须各有文件校验与依赖打包规则。已有图像、视频、音频 API 行为保持兼容。

统一使用 `POST /v1/jobs`、任务 ID 查询与 `/v1/content/{id}/download`。发现接口 `/v1/models`、`/v1/capabilities` 和模型 usage 必须声明输入、预设、输出、权限及限制。此增量不把 3D 冒充 OpenAI 图像/视频接口，也不借用 Sub2API 的图片定价；网关尚未配置独立 3D 结算前明确拒绝该能力。现有六类仍使用原有 Workflow 1.0/1.1；全局 HTTP API 版本维持 0.5.0，通过新增任务类型、Workflow 1.2 和 Worker 能力字段区分兼容性。

## 2. 冻结契约与安全约束

| 项目 | 实现约束 |
| --- | --- |
| 请求 | `task_type=image_to_3d`；`input.source_image.asset_id` 为同 Key 上传的静态图片。该首批流程不消费文字提示，禁止传入 prompt、negative_prompt、mask、references，避免静默忽略。 |
| 参数 | 仅质量预设、seed、固定 n=1；尺寸、视频时长、帧率及任意节点参数拒绝。推理步数、网格深度、部件数、输出格式固定在不可变发布包。 |
| Workflow | `format_version=1.2`、`model3d-glb-v1`；只读取声明的最终保存节点、实际 history 的 `3d` 列表。要求 source_image、seed、output_prefix 全部绑定至最终输出的上游。 |
| Worker | 显式声明 `model3d-output-v1`；旧 Worker 不领取新 3D 任务。继续使用 journal、租约、fencing、物理 GPU 排他和未知提交核对。 |
| 权限 | 独立 `meshes:create` 和 Tenant/Project/Key 三层 `daily_mesh_count`；旧策略缺省为 0，升级不自动增加权限。日任务数、未完成数、生成并发、模型及渠道授权继续适用。 |
| 计量 | 独立 mesh_count，只在云端验证成功时记 1；失败/取消/过期返还预留，重复完成不重复记账，不混入 image_count。 |
| 文件验证 | 校验 GLB 文件头、版本、完整长度、对齐、JSON/BIN 分块、嵌入 buffer、accessor 边界、有限坐标、三角索引与非空几何。拒绝外部 URI、越界、截断、未实现的几何压缩和非自包含引用；不只按扩展名放行。 |
| 内容 | 复用 SHA-256、完整云端回读、不可变对象版本、Key 隔离、HEAD/Range、到期和撤销检查；GLB 走附件下载。元数据展示顶点、三角面、网格、材质及纹理计数。 |
| 保留 | 云端主产物仍从任务成功起保留 8 小时；Worker 暂存仍从云端确认后保留 1 小时。ComfyUI 原始输出及既有 3D 推理工作目录不因本次适配被自动删除。 |

DEV-07～21、23～27、29～32 继续适用。只使用原生进程；不安装模型、不替换 3D 推理节点、不使用 Docker/WSL/虚拟机。当前版本的验证范围是静态三角网格 GLB 交付，网页交互式三维预览另行验收。

## 3. 发布、迁移与验证顺序

先修改机器契约、DTO、领域及校验，再增加非负用量列和缺省拒绝策略；迁移先做原生备份验证。同步 Worker、模型说明、Admin、客户端与测试。云端升级后，受控更新 3080 Worker，核对新 boot/能力，再同步冻结包、实际生成验证、批准及发布。不得手改数据库绕过运行批准。

必测：旧六类兼容；缺失新权限/父级额度拒绝；并发配额与终态唯一；旧 Worker 不领取；真实 GLB 与损坏/伪造/截断/越界/外链拒绝；ComfyUI 预览杂项不误收；跨 Key 下载拒绝、Range/HEAD 与八小时到期；真实 3080 生成、云端完整性与模型说明请求一致。浏览器检查须在 finally 关闭本次页面、上下文和浏览器。

Worker 新 boot 会清除环境验证，保留历史运行批准。升级后可通过现有 `PUT /admin/api/v1/channels/{id}/workflow-bindings` 带 `verify_only=true` 重新验证同一已应用发布：服务端检查原绑定、desired/applied 摘要、运行批准和已应用渠道版本，保留批准但先清空 verified_digest 并排空；实际 Worker 重新核对文件/版本或 API-only 依赖并回执成功后才恢复 verified_digest。新绑定、变更配置、缺失原批准或不一致摘要均拒绝此选项；普通重绑仍清除运行批准。该动作不构成新的生成质量验收，也不能跳过新 3D 发布的真实验证任务。

格式依据：[Khronos glTF 2.0](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)，保存节点依据当前设备实际源码及 [ComfyUI 官方保存节点](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_save_3d.py)。

## 4. 调用与后台逻辑

Admin 先为 Tenant、Project 开启 `daily_mesh_count`，再为业务 Key 分配 `meshes:create`、`assets:upload`、`jobs:create/read`、`models:read`、`capabilities:read`、`artifacts:read`、`content:read/download` 和获准的模型/发布/渠道。仅增加 Key 配额不能绕过父级限额。默认值 0 不会自动扩大现有调用者权限。

模型发现 → 阅读 usage → 同 Key 上传图片 → 按返回的 asset ID 创建任务 → 查询终态 → 读取 artifacts → 下载并核对摘要。这里的“模型”仍是一个固定 Workflow 发布及其可调度渠道的公开别名；未来相同发布绑定多台设备时继续使用现有物理 GPU 排他调度，3D 不引入旁路队列。

```json
{
  "model": "comfy-3080-3d-trellis2",
  "task_type": "image_to_3d",
  "input": {"source_image": {"asset_id": "REPLACE_WITH_UPLOADED_ASSET_ID"}},
  "parameters": {"quality": "standard", "seed": 17, "n": 1}
}
```

先读取线上发现结果确认别名可见，使用稳定 Idempotency-Key 向 `/v1/jobs` POST；请求结果不确定时保留同一 Key 和原始请求，不创建第二次生成。`GET /v1/jobs/{id}` 成功后从 `artifacts[].id` 查询 `/v1/content/{id}`；GLB MIME 为 `model/gltf-binary`，下载仍需原 Key。`metadata` 提供网格、顶点、三角面等计数；这些是实际文件检查结果，不是提示词声称的参数。

Media Gen Skill 1.1.0 用 `generate --model ALIAS --source-image robot.png --seed 17 --wait --timeout 1800`。3D 不传 `--prompt`、`--size` 或 `--seconds`。Admin 在任务/模型列表识别“单图生成 3D”，内容页支持 3D 筛选、元数据和附件下载；可将 GLB 导入 Blender 等工具检查。首版此增量没有网页交互旋转预览，也没有把 768×768 的 ComfyUI 预览画布当成网格尺寸。
