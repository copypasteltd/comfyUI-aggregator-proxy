# 58 · 运行趋势与任务阶段耗时

日期：2026-10-24。状态：本地实现、原生协议/负载、迁移恢复及候选验证通过；真实资源与完整首版未验收。对应 ADMIN-01/07/10/11、WP-02/05/08/09/13/14、DEV-07/09～11/14/15/17/23/25～32。补齐首版总览的时间范围、成功/失败趋势和任务详情耗时；不替代实际 Workflow、设备、对象存储或规模签收。

## 1. 统计口径与接口

新增只读 `GET /admin/api/v1/queues/statistics`，使用独立管理会话及 `queues:read`。业务 Key、Worker、网关身份不能调用。沿用全部队列筛选交集，页码不影响聚合；增加 `window=1h|24h|7d`（默认 24h）、可选六类 `task_type` 和 `include_validation=false`。创建时间筛选仍针对任务创建时间，统计窗口另按受理或结束时间裁决；不把同一任务的多次尝试当成多个任务。

窗口为服务端整秒快照的 `[window_start, window_end)`，不接受客户自报当前时间。1h/24h/7d 分别为 12/24/28 个等宽时段。受理量按 accepted_at，四种终态按 terminal_at；两者不是同一批任务。已结束数量包含 succeeded/failed/cancelled/expired；成功率为 succeeded/(succeeded+failed)，没有该分母时为未知，取消与到期单列。验证任务默认不计入，界面可显式包含；图片、视频、音频同级统计，未知历史类型归入 other，不遗漏总量。

成功任务的端到端耗时从受理到终态，包含等待、准备、生成、回传和恢复等待；以整数毫秒提供实际样本数、缺失样本数、离散 P50/P95。缺失或时序不成立的记录不进入分位数，不能补零。失败按固定的 OOM、产物无效、准备、执行、其他、未分类聚合，只计 failed；不返回原异常、提示词或无限长错误码集合。

同一 PostgreSQL REPEATABLE READ READ ONLY 快照执行聚合，不读取请求/Workflow 图或对象正文，不写审计/outbox，不续约、不改变占用。使用时间索引和固定分组；最多三次有界聚合读取，每条语句上限 1.5 秒、锁等待上限 1 秒。超时返回可重试的脱敏不可用错误，不能伪造空成功。响应上限由时段、六种能力加 other 和固定失败分类限定。

## 2. 可持久恢复的阶段记录

Attempt 增加 nullable 的 preparing_at、submit_intent_at、submitted_at、outputs_collected_at。仅在对应 Worker 事件已通过节点/boot/fence、摘要、序号和状态转换校验后，以控制面时间首次写入，与状态、inbox、审计同事务；重放、失败事务、续约及恢复不覆盖。Worker observed_at 不作为阶段计时来源。旧行不从审计、状态或 prompt_id 猜测回填。

新增的时间索引分别覆盖 Job.accepted_at 和 Job.terminal_at。迁移是加法变更，先停止开发 API/Runner/GC，再原生备份和验证归档后独立升级开发/测试库。若新列已有事实，降级拒绝删除。当前 Worker 协议 0.4.0 继续兼容，不增加 Worker 上报要求。

任务详情新增 timing 和 attempts_has_more；尝试新增 timing。返回相同快照时间的总历时、首次等待及尝试阶段。时长状态为 complete、open、unknown：complete 有两端持久时间；open 是截至快照的观测跨度，明确表示尚无结束记录；缺记录、未来记录、倒序或无法确定结束的历史阶段为 unknown。终态缺少时间不能当成仍在运行。毫秒是整数；时间不成立不截成零。

准备与分配为 Attempt 创建至提交意图；提交为意图至提交回执；生成与收集为提交回执至稳定产物记录（或已有确认的生成释放）；上传与核验为生成释放至该尝试关闭；尝试总跨度为创建至关闭。上述均为控制面观测间隔，可能含网络、ComfyUI 排队、轮询、恢复和文件操作，不宣称是 GPU 忙碌、模型加载或纯编码时间。模型加载暂无独立测量，明确 unknown。GPU 释放仍由既有证据和事务决定，任何计时都不参与调度/重试/结算判断。

详情最多返回最近 100 个尝试，并确保当前尝试优先入选；按创建顺序展示，超过则显式标记。首次分配时间用全链最早尝试聚合，不误用截断列表的第一项。普通详情读取使用只读快照；敏感读取沿原独立权限和审计行为。既有客户端可忽略新增字段，旧数据允许时间未知。

## 3. 图形交互

沿用文档 18 的浅灰、深蓝、青色、铜色、健康绿和异常红，以及本地中文/等宽字体。总览保留当前队列与 GPU 区，增加「生成统计」：时间范围、能力和验证任务控制；受理、四终态、成功率、P50/P95；按时间排列的堆叠趋势和固定失败分类。时段真实顺序决定布局，颜色编码终态；无结束任务显示可理解的空状态，零分母显示未知。图形有键盘焦点、文字替代和同一组真实数值。

公共队列筛选同时作用于统计；统计范围控制只改变统计，不改变当前队列。统计用共用可见性刷新模块，每 5 秒更新；更换条件清空不匹配快照并取消旧请求，同条件失败保留旧快照并显示时间。隐藏、离页和退出停止本页请求与定时器；不增加 SSE 连接。统计快照与队列快照分别标明，不声称跨请求同一事务。

任务抽屉显示总历时、首次等待及每次尝试的阶段列表，unknown/open 有明确标签；不根据本地时钟编造进度。桌面、390px、加载、失败/重试、条件切换、隐藏/退出、只读角色及窗口边界纳入真实浏览器测试；finally 关闭本次所有无用页面、上下文和浏览器。
