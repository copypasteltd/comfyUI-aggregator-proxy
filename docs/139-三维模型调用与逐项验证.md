## 调用方式 / Calls

安装 [Skill 1.3.0](126-MediaGenSkill安装与调用.md)，设置自己的 `MEDIA_GEN_API_KEY`，先 `describe`。单文件 Skill 用户把以下 `scripts/media_gen.py` 换为提取后的 `media_gen.py`。四张多视图素材应属于同一物体，分别对应正面、背面、左侧、右侧；平台按槽位传递，不会自动替调用方判断视角。

```sh
python scripts/media_gen.py describe comfy-3080-uniforge3d-1231f7
python scripts/media_gen.py generate --model comfy-3080-uniforge3d-1231f7 --media front=front.png --media back=back.png --media left=left.png --media right=right.png --seed 17 --wait --timeout 3600 --output-dir model-output
```

单图候选使用声明的 `--media source_image=object.png`；网格精化使用 `--media coarse_mesh=coarse.glb --media source_image=object.png`；UniTexture 贴图使用 `--media source_mesh=mesh.glb --media texture_reference=reference.png`。必须先查询该型号是否已发布并获 Key 授权，再替换 alias。历史单图型号 `comfy-3080-3d-trellis2` 的 `--source-image` 属于旧输入契约，新命名槽位用法以实际 usage 为准。

Each multiview image must match its declared role. Refinement consumes a coarse self-contained GLB plus an image; texturing consumes a GLB plus a texture reference. Do not mix legacy `--source-image` and new named-media contracts.

原生 API 先向 `/v1/assets` 上传图片或 GLB，分别指定 `kind=image` / `kind=model`；然后向 `POST /v1/jobs` 提交 `task_type=image_to_3d`、`input.media: [{"slot":"front","asset_id":"返回的素材 ID"}, ...]`，参数按该型号完整预设。以下约束适用于本轮静态网格型号：

- 所有必填槽位都必须提供自己的有效素材；路径、网址和文件名不是素材 ID。
- `quality=standard`、`n=1`，可传声明范围内的 seed；不接受图片 size、视频 seconds、未声明的 prompt 或任意几何参数。
- 输出为一个自包含、未压缩的静态三角网格 GLB 2.0；不接受外部 URI、动画、蒙皮、稀疏 accessor 或压缩几何。平台上限为 512 MiB、500 万顶点及 1,000 万三角形，具体型号可以更严格。
- 几何、顶点色、UV/PBR 及 UV 贴图由独立冻结变体声明。材质能力按连接到最终输出的链路说明，不对缺失的通道或生成质量作额外承诺。
- Key 需要 `meshes:create` 及发现、任务和内容读取/下载权限；上传另需 `assets:upload`。不能以图片/视频额度替代三维额度；Key、项目及租户共同限制。
- 任务成功后按 `artifacts[].id` 下载 GLB，云端保留 8 小时；运行时长取决于模型、输入、加载和排队，客户端等待超时不意味着服务端任务已取消。

Download the GLB before `expires_at`. A successful generation and complete verified download establish execution and delivery; shape fidelity and material quality require separate review. The platform owns the asynchronous job lifecycle and physical GPU exclusion.

## 验证边界 / Verification boundaries

每个候选分别同步依赖、执行验证任务、取得当前设备和冻结版本的批准，再发布并用普通业务 Key 再次生成、完整下载和核对 SHA-256。失败请求、旧发布及恢复操作保留；源工作流缺失与平台封装或设备环境问题分别记录。[原生依赖和服务权限](136-原生辅助依赖冻结与校验.md) · [材质说明](137-模型家族与三维导出能力说明.md)。

首个 UniForge3D 多视图版本已完成上述全部步骤：[实际调用与 GLB 证明](evidence/2026-11-04/catalog-mesh-145-first-runtime.json)。业务文件为 2,399,092 字节、49,958 顶点、99,689 三角形，含一个材质且无嵌入贴图。本次业务任务从接收到完成约 19 分 2 秒，是一次实际观测，不作为时长承诺；其余 17 个三维候选继续逐项验证。[真实 GLB 的几何预览](media/catalog-145/README.md) 使用明确标记的青柠显示材质，不改变源文件。

The first UniForge3D model passed the complete sequence and returned a 2,399,092-byte static GLB. Its 49,958 vertices and 99,689 triangles are independently inspected. The single material has no embedded textures. The approximately 19-minute business duration is one observation, not a latency promise. Other mesh candidates remain individually pending.
