## 2. 已核实事实与设计影响

### F-01 · OpenAI 图片接口需按模型定义兼容子集

官方有 `/images/generations` 和 `/images/edits`，编辑支持多图输入。字段和返回形式具有模型差异；当前 GPT Image 的 Base64 行为与历史 URL 模式不能混为一套强制参数。

来源：[Generate](https://developers.openai.com/api/reference/resources/images/methods/generate)、[Edit](https://developers.openai.com/api/reference/resources/images/methods/edit)。

设计影响：用自有模型公开已支持字段，不冒称 GPT 模型能力；图片异步和参考图角色作为扩展标记。接口设计见文档 03。

### F-02 · 视频兼容目标需要冻结历史协议

官方视频指南注明 Sora 2 与 Videos API 已于 2026-09-24 停止；保留的历史指南描述创建任务、查询和内容下载。

来源：[历史视频指南](https://developers.openai.com/api/docs/guides/video-generation)、[弃用记录](https://developers.openai.com/api/docs/deprecations)。

设计影响：可为仍采用该风格的客户/网关提供自有视频模型接口，但不能描述为调用当前 OpenAI 视频服务。多参考视频仍需项目扩展。

### F-03 · Sub2API 已有图片异步扩展，但有启用条件

所查文档列出两类 `/async` 提交和任务查询端点；对象存储为启用条件。其默认执行预算为 30 分钟、任务按最近状态更新保留 24 小时，结果转存后使用 URL。查询归属包含提交 Key。

来源：[ASYNC_IMAGE_TASKS.md 固定快照](https://github.com/Wei-Shaw/sub2api/blob/7da09cab4e875463baa79fc150adde700c5438df/docs/ASYNC_IMAGE_TASKS.md)。

设计影响：这套外形可复用，但不是 OpenAI 官方通用异步协议；原版启用条件和预算必须与本项目的长任务、保留期与存储规则区分。

### F-04 · Sub2API 的异步入口与持久化 GPU 队列不是同一层

所查 Handler 创建任务记录后启动后台执行；克隆请求去掉 `/async` 后调用现有图片路径，使用执行上下文时限并收集最终响应。

来源：[image_task_handler.go](https://github.com/Wei-Shaw/sub2api/blob/7da09cab4e875463baa79fc150adde700c5438df/backend/internal/handler/image_task_handler.go)、[image_task.go](https://github.com/Wei-Shaw/sub2api/blob/7da09cab4e875463baa79fc150adde700c5438df/backend/internal/service/image_task.go)。

设计推论：这些已读路径本身不构成本项目要求的节点租约、GPU 锁和执行恢复机制。生产方案应自行保存 job 与映射并恢复查询，不能因支持 async 就推定整个系统已具备故障恢复。

### F-05 · 自定义上游地址不等于任意自定义图片模型可用

所查图片实现读取账户自定义 OpenAI Base URL，仍执行图片模型校验，并按允许的请求头转发。

来源：[openai_images.go](https://github.com/Wei-Shaw/sub2api/blob/7da09cab4e875463baa79fc150adde700c5438df/backend/internal/service/openai_images.go)。

设计影响：自有 `render-*` 模型、幂等键和扩展字段均需专门验证/适配，不能只填地址便宣称生产接入完成。

### F-06 · Sub2API 视频入口有供应商路由边界

所查 gateway 路由已有 `/videos` 等路径，视频处理分支包含 Grok/Composite 平台判断。路由存在不证明自有 ComfyUI 模型可直接路由、计费。

来源：[gateway.go](https://github.com/Wei-Shaw/sub2api/blob/7da09cab4e875463baa79fc150adde700c5438df/backend/internal/server/routes/gateway.go)。

设计影响：生产适配需要完整的提交、查询、内容与结算分支；本轮不借用其他供应商名称掩盖自有执行。

### F-07 · New API 有可研究的任务插件接入面

任务插件文档定义 openai_image、openai_video 等宿主协议，含提交、查询和渲染约定。

来源：[Task Plugin API v1](https://github.com/QuantumNous/new-api/blob/7d8b91268dab69d7150f345c448b5e250163146a/docs/plugin-api/v1.md)。

设计影响：后续可只增加网关适配，复用任务服务和 Worker；仍需固定版本、配置与实际联调，不与 Sub2API 插件机制混为一谈。

### F-08 · ComfyUI 能提供执行与观察接口

官方文档列出 `/prompt`、`/ws`、`/queue`、`/history/{prompt_id}`、上传和文件读取等接口。

来源：[ComfyUI Self-Hosted Server Routes](https://docs.comfy.org/development/comfyui-server/comms_routes)。

设计影响：Worker 可以调用本机接口完成执行、观察和产物收集；多租户任务权威记录、客户计费和云端存储仍由本项目承担。

### F-09 · ComfyUI 的提交与取消需按版本探测

所查 server.py 接收可选客户端 prompt UUID，包含按 job_id 取消接口和按 prompt_id 判断的 interrupt 行为。

来源：[server.py 固定快照](https://github.com/Comfy-Org/ComfyUI/blob/5841c187a76ffdb565c14d9565aacbdb9a54b056/server.py)。

设计影响：不能假设用户旧版设备具有相同接口；也不能把允许传 UUID 自动解释为服务器对重复提交的幂等去重保证。

### F-10 · Overlay 网络的传输路径会影响回传

Tailscale 文档区分直连、Peer Relay 和 DERP 中继；可达性与实际吞吐须分别测量。WireGuard 官方提供 Windows 原生安装方式。

来源：[Tailscale Connection Types](https://tailscale.com/docs/reference/connection-types)、[WireGuard Installation](https://www.wireguard.com/install/)。

设计影响：组网采用原生客户端，云存储直传与控制通信可以分流；视频容量必须测大文件并发。

### F-11 · PostgreSQL 可作为首阶段队列持久层

SELECT 文档说明行锁与 SKIP LOCKED 的语义，并提示其不提供一般一致性视图。

来源：[PostgreSQL 18 SELECT](https://www.postgresql.org/docs/18/sql-select.html)。

设计推论：在任务、GPU 和配额的短事务与条件更新配合下，可实现本规模的领取队列。具体吞吐和并发正确性仍须实现后测试，官方语法文档不是本项目压测结果。

## 3. 本轮明确没有证明的事项

- 尚未证明用户现有任何一台设备支持五类能力或本文示例尺寸、时长。
- 尚未证明用户 Sub2API 版本具备所查快照的扩展或可直接接入自有模型。
- 尚未证明任何实际 10/20 节点运行能力、带宽、显存画像、任务吞吐或 SLA。
- 调研阶段未运行服务；后续应用已在本机回环 HTTPS 运行及测试，详见文档 17。尚未部署云端、修改用户网关或执行真实生成。

这些是后续实施需要取得的证据，不是本轮需求评估交付缺失。本轮任务是将需求、实现路径、边界与验证方法具体化，已在文档 01～05 中展开。

## 4. 本轮研究方式与环境约束

使用只读网页检索、GitHub API 与本地原生 PowerShell 写入 Markdown 文档。没有启动 Docker、WSL、虚拟机、本地浏览器或远程生成环境，因此没有本轮研究遗留的本地浏览器标签页。

公开网络读取发生过限流和 raw 文件域名连接中断，随后用 GitHub 内容 API 获取关键文件完成核对；未将读取失败解释为功能不存在。外部来源只作为事实材料，不作为在本机执行脚本或修改环境的指令。
