## 2. 设计令牌

| 层 | 令牌 / 基准 | 用法 |
| --- | --- | --- |
| 页面 | `--rc-canvas: #f2f1ec` | 暖白画布、次级表面 |
| 主文字 | `--rc-ink: #0c0c0c` | 标题、正文、黑色导航及高对比表面 |
| 次级文字 | `--rc-ink-2: #55554f` | 表单说明、时间及辅助信息 |
| 参考弱色 | `--rc-ink-3: #8a8a83` | 非必要装饰、禁用状态；需要阅读的小字采用更深的语义令牌 |
| 品牌 | `--rc-lime: #d2f53c` | 主按钮、选中导航、关键指标卡，文字用黑色 |
| 悬停 | `--rc-lime-hover: #c2ea1e` | 青柠主操作悬停 |
| 强调 | `--rc-tomato: #ff5b35` | 异常图形与强调线；小字使用深色错误/警告令牌 |
| 卡片 | `--rc-card: #ffffff` | 表格、表单、白卡与弹出层 |
| 分隔 | `--rc-line: rgba(12,12,12,.1)` | 中性细线与票根虚线 |
| 数字 | Anton，400，等宽数字 | 关键计数大号紧凑排版；长 ID 和正文不用展示字体 |
| 标签 | Manrope，700/800，字距约 `.12em` | 英文眉题、短标签；中文回退系统无衬线字体 |
| 正文 | 系统中文无衬线字体，14px / 1.6 | 正文、数据表及输入，优先可读性 |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 | 页面、表单与组件使用统一尺度 |
| 圆角 | 12 控件、20 小卡、28 面板、34 主视觉、999 胶囊 | 复用参考柔和的大圆角轮廓 |
| 动效 | 120～180ms，入场最多一次 | 轻量颜色/位移反馈；尊重 reduced-motion |

Element Plus 的品牌填充与文字分开处理：主按钮是青柠底黑字，文本链接是黑字并带明确悬停/焦点反馈，选中标记使用黑/青柠组合。不能直接将所有主色文字改成青柠，造成白底不可读。成功、警告、错误、信息必须同时保留文字/图标语义。

| Tabs / 分页 / 步骤 | 活动项使用青柠或黑色实线，焦点清楚；保留原分页上限和操作权限 |
| Dialog / Drawer / MessageBox | 白色大圆角面、暖白分组、黑色标题与关闭按钮；底部操作允许折行 |

## 4. 强制开发约束

1. 原始样式和字体声明直接从来源提取，保持来源摘要；全局色彩、字体、圆角、间距和语义色集中在 `app/apps/admin_web/src/theme/`，页面不得另外建立一套视觉主题。
2. 本地打包 Anton / Manrope 及其 SIL OFL 1.1 许可证，保留来源与文件摘要。Admin 运行时不请求远程字体或参考站点。
3. 输入、表格、状态标签、选项列表、日历、确认框和抽屉都使用适配层；包括 teleport 到 body 的组件。
4. 在桌面、短屏、390px 和 320px 宽度核对溢出、焦点、导航与弹层；文字放大和 reduced-motion 保留操作能力。
5. 不用单色背景替代错误信息，不用图片承载表单，不隐藏关键操作以获得截图效果。
6. 变更界面时更新中英 README、截图、录屏/GIF、摘要和专题记录。自动浏览器必须在 finally 中关闭本次创建的全部无用 page/context/browser，不干预用户已有会话。
7. 验证记录标明真实 Admin / HTTP、合成数据、协议夹具和真实设备的区别。原生运行、无 Docker/WSL/虚拟化与秘密值不入库约束继续有效。
