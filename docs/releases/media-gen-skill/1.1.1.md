# Media Gen Skill 1.1.1

同步云端 129.3 的 3D 兼容修复与调用说明。最小权限 Key 使用 `meshes:create`、源图上传与任务/内容权限即可调用，不需要 `images:create`；Tenant、Project、Key 的 `daily_mesh_count` 仍需显式开启。补齐单图生成请求、GLB 几何字段、完整/HEAD/Range 鉴权下载及手动 `.glb` 文件名说明。Agent 展示说明覆盖图片、视频、音频和 3D，客户端 User-Agent 同步至 1.1.1。

Aligns the Skill with cloud 129.3: mesh-only callers need `meshes:create`, asset upload and job/content scopes, without `images:create`. Tenant/Project/Key mesh quotas remain explicit. Documents image-only requests, actual geometry metadata, authenticated GET/HEAD/Range and automatic versus explicit `.glb` filenames. Agent metadata lists all four output kinds; the client identifies itself as version 1.1.1.

保留原有图片、视频、音频、参考图、异步任务与幂等恢复用法。未知提交继续使用原 Key、请求和幂等键，成功任务恢复不会重复生成或延长八小时期限。此 Skill 更新不升级其他部署的服务端或 Worker。

Image/video/audio, reference inputs and asynchronous recovery remain available. Resume uncertain submissions with the original Key, body and Idempotency-Key; completed jobs do not regenerate or extend expiry. This Skill package does not upgrade another deployment's server or Worker.

当前 3D 限单图生成静态自包含三角网格 GLB 2.0，不代表支持 OBJ、FBX、多文件 glTF、动画/骨骼、交互预览、材质/打印质量或 Sub2API 3D 结算。生成能力与参数以实时发现接口为准。

3D is limited to one-image generation of static, self-contained triangle GLB 2.0. OBJ/FBX, multi-file glTF, animation/skinning, interactive previews, material/print quality and Sub2API 3D settlement are outside this profile. Discover live models, presets and permissions before use.

Assets: `media-gen-skill-1.1.1.zip`, `SHA256SUMS.txt`, `release.json`. Verify SHA-256, extract the single `media-gen-skill/` directory, replace your previous installed Skill directory, and open a new agent session. Keep private credentials, request-state files and downloaded outputs outside that directory. Configure `MEDIA_GEN_API_KEY` yourself; no credentials or weights are included.

资源：ZIP、摘要与来源清单。校验后解压并更新已安装的 Skill，重新打开 Agent 会话；凭证、恢复状态和已下载文件应保存在独立位置。完整安装见 [126](https://github.com/copypasteltd/comfyUI-aggregator-proxy/blob/main/docs/126-MediaGenSkill安装与调用.md)，服务端复查见 [129](https://github.com/copypasteltd/comfyUI-aggregator-proxy/blob/main/docs/129-三维兼容复查与GLB边界修复.md)。
