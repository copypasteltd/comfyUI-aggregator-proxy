## 与当前 ComfyUI 方向的选型关系

| 目标 | 优先考察 | 原因与尚需开发内容 |
|---|---|---|
| 自建图像 / 视频 / 音频任务节点画布 | [React Flow](https://github.com/xyflow/xyflow)、[Vue Flow](https://github.com/bcakmakoglu/vue-flow)、[FlowGram](https://github.com/bytedance/flowgram.ai) | 节点、连线和表单扩展与生成任务较匹配；仍需接入模型目录、异步任务、素材上传下载、鉴权及状态回传。 |
| 自建自由摆放图片、文本和图形的白板 | [Excalidraw](https://github.com/excalidraw/excalidraw)、[Drawnix](https://github.com/plait-board/drawnix)、[Plait](https://github.com/worktile/plait) | 已有白板交互；图视频音频节点和生成过程需要扩展。 |
| 强调自由图形编辑的底层引擎 | [LeaferJS](https://github.com/leaferjs/leafer-ui)、[Konva](https://github.com/konvajs/konva)、[Fabric.js](https://github.com/fabricjs/fabric.js) | 图形表现可定制；历史记录、协作、文档结构和业务工作台需按产品构建。 |
| 参考 AI 创作成品的业务设计 | [Toonflow](https://github.com/HBAI-Ltd/Toonflow-app)、[AICON](https://github.com/869413421/ai-moive-studio)、[NovaNova Studio](https://github.com/Swayingleaves/novanova-studio) | 可参考素材、分镜、生成与项目组织；与现有代理 API 的适配尚未实测。 |
| 重点参考多 ComfyUI 节点的分镜生成 | [Director’s Console](https://github.com/NickPittas/DirectorsConsole) | 已有 ComfyUI 工作流与多节点创作思路；不能据此认为已经具备现有平台的公网权限与管理能力。 |
| 文档、笔记和协作画布融合 | [BlockSuite](https://github.com/toeverything/blocksuite) | 提供可复用编辑器与协作数据层；比纯节点任务画布更适合文档空间。 |

以上是基于项目公开功能的初步匹配判断，不是性能或接入实测结论。若后续仍围绕现有 ComfyUI 聚合服务开发，优先比较 React Flow / Vue Flow / FlowGram，并将生成 API 当作后端能力接入。
