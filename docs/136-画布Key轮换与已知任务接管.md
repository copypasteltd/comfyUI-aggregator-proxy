原身份、原正文、幂等键、发布摘要、项目、节点和画布种子冻结。关联绑定目标身份/原ID/原提交快照SHA；写入前重查客户端、原快照和任务ID。并发两页按最新记录合并，重复确认不重复关联；连接切换、记录变化、错误响应、配额或事务失败均保留原记录。解除只移除当前关联。新Key下载保存到新身份，原画布及可重建任务保护新副本；旧缓存不迁移。

清单按原身份导出，权限证明不导出。可显式恢复同源旧身份清单，不自动查询/上传/生成；已知任务逐项重新核对。清单不含画布或原件，跨浏览器需另备作品ZIP。备份SHA不证明服务端授权或提示词原文。为防止旧客户端不了解新身份的引用后误删，浏览器日志库升级到v4；保留v1/v2/v3仓库，旧v3页面必须重载，不能回退静态包降级。服务端数据库无迁移，无第二套队列。
