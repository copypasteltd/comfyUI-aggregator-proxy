Agent
连接本地 Agent
按使用场景选择一种连接方式。
方式一：在 Codex 中使用插件
在 Codex app 安装 Infinite Canvas 插件后，通过插件启动画布，插件会自动启动本地 Agent 并带上连接信息。
Codex 插件提醒
只有安装 Codex 插件或手动添加 MCP 后，工具列表才会进入 Codex 上下文并增加 token 消耗；仅运行 npx -y @basketikun/canvas-agent@latest 启动本地 Agent 不会安装 MCP。
移除插件codex plugin remove infinite-canvas
移除手动 MCPcodex mcp remove infinite-canvas
方式二：直接运行 Agent
不使用 Codex 插件时，在终端运行下面命令，再回到网页里连接或手动填入 Local URL 和 Connect token。
npx -y @basketikun/canvas-agent@latest
网页连接未连接
默认自动读取 Local URL 和 Connect token，失败时再手动填写。
