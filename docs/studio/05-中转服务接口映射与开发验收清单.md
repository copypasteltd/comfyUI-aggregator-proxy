# 05 · 中转服务接口映射与开发验收清单

基于本地原版 `9cd3deacbcc598361807afc16c059a80dd18b6f9` 与中转服务 `f522ee0d70b74db137c9f858446ba58c2f508a50` 的源码核对。本文件是开发准备，不是接口运行成功记录。初步架构见 [04](04-本地源码与中转服务融合方案.md)；后续完整约束和实际验证见 [06](06-融合可行性评估与上线约束.md)、[07](07-融合实现契约与故障恢复.md)、[08](08-可用性验证与发布验收.md)。

## 1. 已有接口如何复用

以下路径均相对中转服务源站，业务请求使用用户自己的 `Authorization: Bearer …`。

| 编号 | 用途 | 已有接口 | 画布接法 |
| --- | --- | --- | --- |
| API-01 | 当前授权 | `GET /v1/access-policy` | 查看 Key 的权限/规格/额度限制，不能当 Admin 登录 |
| API-02 | 模型发现 | `GET /v1/models`、`GET /v1/models/{model}` | 完整保留 `usage`：名称、说明、注释、任务类型、Schema、参考槽位 |
| API-03 | 能力与发布 | `GET /v1/capabilities` | 取得版本/摘要、参数和完整预设；与模型说明一起构造表单 |
| API-04 | 上传参考 | `POST /v1/assets`，multipart 字段 `file` | 得到同 Key 的 `asset_id`；不是浏览器直接给 ComfyUI 上传 |
| API-05 | 创建任务 | `POST /v1/jobs` | JSON 指定 `model/task_type/input/parameters`，显式持久幂等键 |
| API-06 | 恢复与历史 | `GET /v1/jobs/{identifier}`、`GET /v1/jobs` | 恢复原任务；列表按当前 Key 范围、游标和服务端筛选 |
| API-07 | 取消任务 | `POST /v1/jobs/{identifier}/cancel` | 取消远程意图，202 不等于 GPU 已停止 |
| API-08 | 结果元数据 | `GET /v1/content/{identifier}` | 从任务 `artifacts[].id` 获取 MIME、字节数、SHA-256、实际媒体元数据、到期时间 |
| API-09 | 结果下载 | `GET/HEAD /v1/content/{identifier}/download` | 原 Key 鉴权；读取为 Blob，验证后保存，Range 依能力使用 |
| API-10 | 图片兼容 | `/v1/images/generations`、`/v1/images/edits`，以及各自 `/async` 和 `/v1/images/tasks/{identifier}` | 作为既有兼容能力保留；融合版统一任务避免同步等待和多套恢复逻辑 |
| API-11 | 视频兼容 | `POST /v1/videos`、`GET /v1/videos/{identifier}`、`GET/HEAD …/content` | 保留外部兼容；原版视频表单不能原样提交 |

原版 `buildApiUrl` 会自动补 `/v1`；适配器需区分“源站”与完整相对路径，不能再次把 `/v1/jobs` 拼成 `/v1/v1/jobs`。本地约定连接配置保存规范化源站，固定接口由适配器构造。

生成最低权限由实时 `usage.required_scopes` 确认：通用创建/读取、对应媒体创建、参考上传和结果读取/下载分别有权限。取消按现有服务的业务身份/资源授权执行，不能凭空新增一个实际不存在的 `jobs:cancel` scope。

```text
infinite-canvas/web/src/
├─ services/api/aggregator.ts           源站约束、目录/上传/任务/下载 API
├─ stores/use-aggregator-store.ts       目录/授权状态与持久任务恢复
```

用现有 Zustand/localforage 和服务目录，不增加第二种全局状态管理。3D 渲染库只在交互预览工作包开始后评估，不为下载卡先引入大依赖。参考源和字体许可证需随复制记录摘要；管理后台的源码规范/发布约束仍归原项目。

中转服务如需修改部署入口或新增 API，后续在 `无限画布/` 内建立原服务的隔离工作副本/分支，在其中 `app/` 开发，满足“后续构建位于本路径”的要求；仍执行原仓库门禁，更新双语 README、专题、CHANGELOG 并同步其远端。当前相邻原仓库只读，未创建该后端开发副本或修改/推送。画布正式新增功能后按上游 AGENTS 记录 todo/pending-test/Unreleased；当前下载的原版未改变功能，因此不改写这些上游文件。

## 4. 任务记录与异常规则

拟持久记录包含：连接身份引用、画布/节点 ID、原始任务请求及 SHA-256、幂等键、提交阶段、已知 job ID、最后服务状态/版本、content ID、MIME/字节数/hash/expiry、本地 storageKey 和明确的保存状态。任务记录不包含明文 Key；提示词和输入关联属于用户内容，不公开日志。

| 场景 | 必须行为 |
| --- | --- |
| 提交前本地写入失败 | 不发送生成 POST，告知无法保证恢复 |
| 提交结果未知 | 保留意图，以原身份/正文/幂等键核对，不换 Key 自动重提 |
| 已知 job ID 后刷新 | 只查询该 ID；不得默认执行新的生成 |
| 401 / 403 | 停止自动提交，显示鉴权/权限问题；不切换其他 Key 重试 |
| 409 幂等冲突 | 保留原始正文并提示核对，不丢弃键重新创建 |
| 422 | 显示参数或参考槽位不匹配，重新读取能力；不擅自替换质量/模型 |
| 429 | 读取 Retry-After，保留任务与请求意图，不制造新的任务 |
| 5xx / 断网 / 页面后台 | 区分查询失败与生成失败；未知创建按原幂等记录恢复 |
| 取消后 | 查到服务端最终状态才更新为取消完成，保留仍在核对的状态 |
| 下载失败 | 只重试读取原内容，不重新生成；云端过期显示不可再下载 |
| 本地空间不足 | 明确未保存；允许用户另行下载，避免无提示丢弃旧素材 |

新轮询预算、重试上限、缓存上限或自动清理阈值属于行为变更，实施前应按适用开发指令明确说明并处理确认；本文没有静默设定新的数值。现有服务端超时和八小时到期继续由服务控制。

## 5. 编号验收清单

所有项目当前均待融合实现与验证，不以静态核对代替。

| 编号 | 验收项目 | 最低证据 |
| --- | --- | --- |
| ACC-01 | 目录与授权 | 同一 Key 的模型/说明/能力一致，非法 Key 拒绝，缺权限不误报可用 |
| ACC-02 | 文生图 | 一条真实已发布流程，经画布提交、原任务查询、完整文件校验 |
| ACC-03 | 单图编辑 | 同 Key 上传，模型允许的源图/参数，实际结果与尺寸 |
| ACC-04 | 多参考生图 | 精确数量/角色/顺序；缺图、多图、错角色拒绝 |
| ACC-05 | 文生视频 | 真实时长/尺寸/媒体格式；无未知字段被忽略 |
| ACC-06 | 参考生视频 | 发布的首帧和多参考模型分别验证，声明不支持的参考类型不能提交 |
| ACC-07 | Workflow 音频 | YuE2 等实际音频模型，真实 MIME/时长/采样率，非 TTS 参数不会被误传 |
| ACC-08 | 单图生 3D | TRELLIS2 等实际 GLB 路径，完整性和附件下载；预览完成另记 |
| ACC-09 | 幂等与恢复 | 模拟响应丢失、刷新、双击、多标签；相同意图无重复 GPU 生成 |
| ACC-10 | 取消与异常 | queued/running/reconciling、客户端提交未知，断网/超时/429/403，不误判停止或换机重提 |
| ACC-11 | 内容权限 | 不同 Key 的任务、元数据、HEAD/Range/下载按实际共享授权隔离 |
| ACC-12 | 素材期限 | 显示 expires_at，本地已保存可用、未保存过期可解释；云端 GC 不冒充本地 GC |
| ACC-13 | 缓存和内存 | 缓存失败状态、引用扫描、退出/删除后的 URL 释放，大文件不重复 base64 常驻 |
| ACC-14 | 移动端 | 390px 无页面级溢出，工具栏可用，Android/iOS 真机触控/软键盘/后台恢复/下载 |
| ACC-15 | 青柠全覆盖 | 设置、工作台、画布、任务、素材、所有弹层；焦点、可读性、reduced-motion 与截图 |
| ACC-16 | 部署和边界 | `/studio/` 资源/深链/插件正常，`/admin/` 与 `/v1/` 路由正确，原内部接口拦截有效 |
| ACC-17 | 多设备与队列 | 同模型多渠道使用后端实际调度；用户只见获准任务，管理视图有全局/分渠道真实数据 |
| ACC-18 | 回归与发布 | 已有非中转 OpenAI/Gemini 通道、构建/类型检查、来源/许可证、说明、可回滚包 |

真实模型当前若不可用，应保留该验收项为阻塞并说明实际原因；不能用另一个媒体调用或 mock 代替签收。测试过程遵守不使用本地虚拟化、浏览器 finally 关闭自建无用页面和上下文的约束。
