# 已发布 Workflow 分类目录 / Published workflow archive

45 个已发布模型入口均保留原别名及冻结版本。工程文件在 `app/workflows/presets/`；各设备面板的 Workflows 中新增 `平台预设/2026-11-16/`。进入 [原生工作台](https://gen.sub2share.xyz/origin/) 鉴权后选择对应设备即可查看。

All 45 published aliases and frozen releases are preserved. Repository artifacts live in `app/workflows/presets/`; native devices receive `平台预设/2026-11-16/` under Workflows. Authenticate at the [native workspace](https://gen.sub2share.xyz/origin/) and select the device.

| 文件 / File | 用途 / Purpose |
| --- | --- |
| `workflow.api.json` | 已审阅冻结执行图的可移植模板；媒体、文本和输出前缀改成明确示例。Reviewed execution template with portable media/text/output examples. |
| `workflow.ui.json` | 由真实 ComfyUI 前端转换的编辑画布，含青柠说明节点及完整 API 图副本。Native editable canvas with a Lime instruction note and embedded complete API template. |
| `bindings.json` | API 参数到节点输入的映射。API-to-node input bindings. |
| `usage.json` / `request.json` | 公开模型说明、输入要求及业务 `/v1/jobs` 请求示例。Public model usage and business job example. |
| `release.json` | 服务端冻结发布 ID、版本及原 manifest 摘要。Server release identity and original manifest digest. |
| `preset.json` | 分类、设备、源站新路径、缺失节点观察与前端差异。Category, device, native path, observed missing nodes and frontend differences. |
| 根 `catalog.json` / `checksums.json` | 45 项完整索引和全部归档文件 SHA-256。Complete catalog and archive file digests. |

`release.json.digest` 对应服务端原始 manifest，`checksums.json` 对应归档副本，不能互换。设备专用私有路径仅在对应设备副本中恢复，公开版本使用占位符；原始冻结快照与本地路径映射另外私密保存。

The release digest identifies the original server manifest; archive checksums identify these copies. Device-specific private paths are restored only on their native device, with explicit placeholders in public files. Original frozen snapshots and local path mappings are retained privately.

## 继续调用 / Calling existing models

先用同一业务 Key 查询 `GET /v1/models` 和 `GET /v1/models/{alias}`（响应中的 `usage`），按 usage 上传素材到 `/v1/assets`，再替换对应 `request.json` 中的 `asset_REPLACE_...`、文本和参数。提交 `/v1/jobs` 后按任务 ID 查询、下载；客户素材不写进仓库。

Use the same business Key to discover `/v1/models` and `/v1/models/{alias}` (the `usage` field), upload required media through `/v1/assets`, then replace example asset IDs/text/parameters in `request.json`. Submit `/v1/jobs`, poll the task and download its result. Keep customer media outside Git.

```powershell
$env:MEDIA_GEN_BASE_URL = 'https://gen.sub2share.xyz'
# Set MEDIA_GEN_API_KEY privately / 私密设置，不写入请求文件或仓库。
curl.exe "$env:MEDIA_GEN_BASE_URL/v1/models" -H "Authorization: Bearer $env:MEDIA_GEN_API_KEY"
curl.exe "$env:MEDIA_GEN_BASE_URL/v1/jobs" -H "Authorization: Bearer $env:MEDIA_GEN_API_KEY" -H "Content-Type: application/json" -H "Idempotency-Key: REPLACE_WITH_NEW_UNIQUE_REQUEST_ID" --data-binary '@app/workflows/presets/images/text-to-image/comfy-3080-12-wai-illustrious-v17-exact-c249e8/request.json'
```

`request.json` 是业务请求，`workflow.api.json` 是原生节点执行图，`workflow.ui.json` 是画布，三者用途不同。未知提交响应保留原请求及幂等身份，先核对；不换 ID 重投。保留原并发、设备占用和权限规则。

The request, native API graph and editable canvas are separate formats. Preserve the original request/idempotency identity after an uncertain submission and reconcile it before retrying. Existing concurrency, reservations and permissions still apply.
