## 先发现，再选择 / Discover before choosing

用自己的业务 API Key 查询 `GET /v1/models`，再读取 `GET /v1/models/{alias}` 的 `usage`。模型名称用于阅读，完整 alias 用于调用；不能按源文件名猜测能力。只有 Key 允许的已发布型号才对该 Key 可见。Admin 需给 Key 配置相应模型、版本、渠道和额度；本轮试跑没有扩大已有客户 Key 的权限。

音频调用使用 `text_to_audio`；相关权限为 `models:read`、`jobs:create`、`jobs:read`、`audio:create`、`content:read`、`content:download`。带参考声音时还需 `assets:upload`；按客户端实际读取接口补充 `assets:read`、`artifacts:read`。Key、项目、租户的最小额度共同生效。

Discover each model's current `usage` with your own Key. Admin grants model/release/channel access and quotas; publishing a model does not widen existing customer Keys. Supply exactly the advertised media/text slots and complete preset.

## Skill 调用 / Skill calls

先按 [126 · 安装与调用](126-MediaGenSkill安装与调用.md) 安装 Skill 1.3.0，并设置 `MEDIA_GEN_API_KEY`；在解压目录执行以下命令。单文件 Skill 用户提取内嵌客户端后，把 `scripts/media_gen.py` 换为 `media_gen.py`。`voice1.wav`、转写和台词文件由调用方提供。

```sh
python scripts/media_gen.py models
python scripts/media_gen.py describe comfy-3080-03-fireredtts2-347a5d
python scripts/media_gen.py generate --model comfy-3080-03-fireredtts2-347a5d --media speaker_1=voice1.wav --text-file s1_text=voice1-transcript.txt --text-file dialogue=single-dialogue.txt --seconds 30 --wait --timeout 1800 --output-dir audio-output
```

`single-dialogue.txt` 示例：`[S1] Hello. This is a short test.`。转写文件必须写 `voice1.wav` 的实际原话。双人 MOSS 型号对应调用：

```sh
python scripts/media_gen.py generate --model comfy-3080-01-moss-tech-ba95ea --media speaker_1=voice1.wav --media speaker_2=voice2.wav --text-file s1_text=voice1-transcript.txt --text-file s2_text=voice2-transcript.txt --text-file dialogue=two-speaker-dialogue.txt --seconds 30 --wait --timeout 1800 --output-dir audio-output
```

双人台词可逐行写 `[S1] Hello.` 与 `[S2] Welcome.`；不能给单人型号传入没有参考录音的第二角色。音乐的两个输入模式分别为：

```sh
python scripts/media_gen.py generate --model comfy-3080-01-yue2-full-bf16-abc-music-2e68f4 --text "style=Cheerful instrumental chamber music, no vocals." --seconds 30 --wait --timeout 1800 --output-dir music-output
python scripts/media_gen.py generate --model comfy-3080-00-yue2-full-bf16-text2music-77ea35 --text "style=Cheerful instrumental chamber music, no vocals." --text-file abc=score.abc --seconds 30 --wait --timeout 1800 --output-dir music-output
```

A02 根据风格及选填歌词在内部生成 ABC；A01 暴露选填 `abc`，允许传入自己的曲谱。选填歌词用 `--text-file lyrics=lyrics.txt`。这些新型号使用 `input.texts`；历史 `comfy-3080-music-yue2` 仍沿用自己的 prompt/冻结歌词契约。[输入归属更正](evidence/2026-11-04/music-input-correction-144.json) 保留原历史报告，明确公开的 catalog-142 音乐样本实际只传入 style。

A02 generates its ABC internally from style/optional lyrics. A01 exposes an optional caller-supplied `abc` field. Existing legacy music aliases retain their own contracts. Do not invent a generic prompt field when the selected schema advertises named text inputs instead.

[业务 Key 的后续复查](evidence/2026-11-04/catalog-music-145-business-discovery.json) 已从真实公开接口确认两条修正后的音乐名称、说明、备注和文本槽位均生效，保留原发布版本与业务任务，没有重复生成。

## 原生 API 与交付 / Native API and delivery

自动作谱音乐的最小请求，可提交到 `POST /v1/jobs`：

```json
{
  "model": "comfy-3080-01-yue2-full-bf16-abc-music-2e68f4",
  "task_type": "text_to_audio",
  "input": {"texts": {"style": "Cheerful instrumental chamber music, no vocals."}},
  "parameters": {"quality": "standard", "seconds": 30, "n": 1, "seed": 17}
}
```

使用同一 Key 查询任务状态及排队信息；成功后按 `artifacts[].id` 下载完整文件。参考声音先上传 `/v1/assets` 且指定 `kind=audio`，再按模型槽位填入 `input.media`，不能把设备路径当作素材 ID。客户端负责上传、轮询和下载恢复。

云端产物在成功完成后保留 **8 小时**；在返回的 `expires_at` 前下载保存。30 秒是输出上限，短台词自然结束不会为了凑时长自动补音频。调用和非静音检查通过不等于语言、声线相似度或音乐质量已经人工验收。

Public samples include [30-second generated music](media/catalog-142/README.md) and [FireRedTTS2/MOSS single-speaker speech](media/catalog-144/README.md). Workflow metadata is removed, with unchanged decoded audio and separate download/public hashes. The [single-speaker recovery](evidence/2026-11-04/single-speaker-recovery-144-runtime.json) preserves the original failed request and its successful fresh retry. [Guide checks](evidence/2026-11-04/audio-guide-144-local.json) verify all nine aliases and parse/build all four generation commands against their current schemas with explicitly offline upload stubs. Related metadata changes pass [53 scoped checks](evidence/2026-11-04/catalog-music-144-local.json) and [213 actual usage inspections](evidence/2026-11-04/catalog-music-144-live-usage.json); they do not change the frozen execution graphs.
