# 37 · 任务与内容游标及共享访问

2026-10-23，接续 [36](./36-Sub2API模型发现与能力投影.md)，涉及 DEV-07、11～19、23～27、29～32。先冻结公开/网关集合契约、Provider 原目标路由与共享访问边界，再同步实现、迁移、客户端和验证。完整 Provider、真实设备、五类 Workflow、私有 S3 和跨服务运行验收仍属于首版范围。

## 集合契约

公开和网关 GET /v1/jobs、GET /v1/content 使用 limit（默认 50，1～100）与 cursor。返回 object=list、data、has_more、next_cursor；末页 next_cursor=null。撤销页码分页，不把 page 当成 cursor。未知/重复查询参数拒绝，避免调用方误以为过滤已生效。模型过滤 model 为公开别名；任务还允许 status 过滤。输入素材继续通过独立 assets 接口处理；内容集合本增量包含已发布的输出，素材聚合、标签与其他检索要求继续保留在完整内容管理范围。

控制面按 created_at DESC、id DESC 做 keyset 查询，先应用当前授权、服务归属、模型/状态过滤，再取 limit+1。只查询当前 Key 的任务；内容沿用 owner_only、shared_creator_keys、project_shared 的显式授权及租户边界。网关集合额外限定 GatewayAdmission 属于当前服务，不能混入本地直连或其他网关的记录。未验证、过期、逻辑删除或已申请对象删除的产物不进入集合。网关内容项额外携带经授权原任务的 external_task_ref、model、task_type，供 Provider 绑定原目标；公开条目不泄露这些内部路由字段或身份。

游标使用服务端加密认证，绑定用途、逻辑主体、当前策略摘要、服务、排序版本、过滤、页大小及创建时间上界。固定有效期 15 分钟，翻页不延长；损坏/错主体/错过滤为 400 invalid_cursor，认证后的过期游标为 400 cursor_expired。凭证轮换保持同一逻辑 Key 时仍可翻页；撤销身份或权限立即拒绝。策略变化要求重新获取首屏。每页重新授权，游标不授予读取权限。创建时间上界和不可变排序避免新插入记录挤动偏移；这不是跨请求数据库快照，晚提交、删除和授权变化仍可能改变后续可见集合。

## Provider 列表与路由

GET /v1/jobs 列举当前实例、上游用户和逻辑 Key 的持久意图，保留尚未得到远端 job 的准入任务。先按当前本机规则、上游分组/白名单及远端 jobs:read 范围筛选，再分页；已绑定任务按原网关查询当前安全投影，不伪造 GPU 阶段。集合不预留资金、不创建新任务、不修改原路由。

GET /v1/content 只从当前本机规则允许的固定目标读取控制面授权集合，不向客户提供的地址探测。跨目标按 gateway ID、model、远端 created_at DESC/id DESC 的确定顺序续读；不声称跨网关全局时间排序。每请求最多处理八个流、最多八个集合请求并发，整轮 10 秒；即使本页没有可见条目，未完成流仍返回续读游标。远端 401/403 省略该流，其他错误拒绝本页，不冒充完整结果或使用旧授权。外层游标绑定当前实例/主体、本机流配置、过滤、页大小和固定到期时间；内部游标不可直接替代公开游标。

Provider 对经当前主体授权的内容保存不可变路由索引，记录固定网关、远端 job、公开模型/能力和原任务引用。该索引只决定查哪里，不授予读权限；每次元数据、GET/HEAD/Range 都向原目标提交当前主体，控制面再核对显式共享与生命周期。配置变化不能把同一个已知 content ID 改路由到另一网关；重复和矛盾路由须拒绝。原属关联与发现路由使用同一事务级锁及数据库触发器核对，避免两个索引并发写入矛盾目标。查询/共享索引不进入资金事务，不跨 HTTP 持有数据库锁。

Provider 外层游标最多 8192 字符，使用现有版本化密钥做带主体/用途/配置摘要的 AEAD 加密；远端控制面游标最多 4096 字符，外层不延长内部到期时间。跨目标的创建时间上界由各流首屏固定，不能把外层签发时间描述为所有网关的同一数据库快照。任务状态过滤须读取原目标的当前状态，每页最多扫描 100 个已在 SQL 授权的候选，达到预算仍返回续读位置，允许无匹配项的一页继续查询。列表不加载完整 Workflow、执行图或提示词；敏感输入保留在有独立权限的任务详情。

GET /v1/jobs 和 GET /v1/content 纳入已有精确的账务鉴权例外，余额或 Key 期限/额度耗尽后仍可查询已有记录；原上游仍检查 Key/用户启停、IP 与当前分组，集合继续检查委托身份和当前业务权限。该例外仅覆盖这两个 GET 集合，不覆盖新建、其他方法或普通上游路由，固定的两处原版补丁范围不增加。

共享读取不扩大任务访问、输入素材读取或删除权限。共享 Key 即使具有 content:delete 也不能删除其他创建者内容；删除继续要求本地原属关联和远端原创建者身份。原属查询与共享查询均受当前上游模型/分组策略约束。没有经授权路由的直接 ID 请求统一为 404，不遍历全部网关猜测归属。

## 验证出口

使用原生 PostgreSQL 覆盖同时间戳分页、翻页间新增/删除、上界、错主体/过滤/页大小/用途、损坏与过期游标、当前权限撤销、凭证轮换、未验证/到期/删除对象以及网关服务隔离。真实 HTTP 鉴权覆盖公开与网关集合；共享内容验证只读、撤销后立即拒绝、跨租户拒绝、下载与 HEAD/Range 一致。

Go 客户端核对受限查询和有界 JSON，拒绝重复键/ID、错误字段/类型、游标矛盾、错误任务/媒体类型及错误原任务引用。Provider 验证固定原目标、共享索引重放/冲突、同名跨目标、当前分组/Key/远端权限、流推进与取消/容量释放，回归现有账本、恢复、生成、编辑、素材、媒体及模型发现。迁移先做备份和可读性检查，临时库重放，实际服务器原生编译；OpenAPI、TypeScript、路由清单、文档和证据摘要同步。
