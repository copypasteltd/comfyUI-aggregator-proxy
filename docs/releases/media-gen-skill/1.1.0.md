# Media Gen Skill 1.1.0

Adds native image-to-3D generation when the deployment advertises an approved model. Discover the model, supply `--source-image`, omit text prompts, and retrieve a verified `.glb` artifact. Existing image, video and audio commands remain supported. / 新增原生单图生成 3D：先发现模型，再传入源图，下载并核对 GLB；保留原有图像、视频和音频调用。

Configure `MEDIA_GEN_API_KEY` with a business Key. 3D requires `meshes:create`, source uploads and explicit Tenant/Project/Key 3D quotas. This package does not include a Key or model weights. / 使用业务 Key；3D 权限及三级额度需要 Admin 显式开启，包内不包含凭证或权重。

The client preserves exact request state before POST, resumes an uncertain submission with the same identity and Idempotency-Key, and checks downloaded bytes/SHA-256. Outputs normally expire eight hours after success. / 提交前保存恢复状态，未知结果沿用原请求与幂等键，下载核对大小和摘要，成功产物通常保留八小时。

Assets: deterministic Skill ZIP, SHA256SUMS.txt and release.json. Extract the ZIP and read SKILL.md and references/api.md. Full implementation and acceptance scope: [128 · 3D adaptation](https://github.com/copypasteltd/comfyUI-aggregator-proxy/blob/main/docs/128-ComfyUI三维模型产物与3080适配.md). Native 3D support does not add Sub2API 3D billing or interactive Admin mesh previews.
