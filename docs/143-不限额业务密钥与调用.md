## 外部调用

Base URL 为 `http://43.165.167.179:39443/v1`，请求头为 `Authorization: Bearer YOUR_API_KEY`。每把 Key 均可独立使用。

```sh
curl -H "Authorization: Bearer YOUR_API_KEY" \
  http://43.165.167.179:39443/v1/models

curl -H "Authorization: Bearer YOUR_API_KEY" \
  http://43.165.167.179:39443/v1/models/MODEL_ALIAS

curl -H "Authorization: Bearer YOUR_API_KEY" \
  http://43.165.167.179:39443/v1/access-policy
```

先读取模型详情中的 `usage`。需要参考图片、源视频或参考声音时，按声明的 `kind` 上传到 `/v1/assets`，把返回的 `asset_id` 放入 `input.media`，再提交 `/v1/jobs`；脚本、歌词、转写分别放入声明的 `input.texts`。随后用同一 Key 查询任务和下载内容。[完整模型调用说明](134-新增模型目录与调用说明.md)与[单文件 Skill](131-单文件Skill与固定在线地址.md)继续适用。

## English

Three independent business API Keys were issued on 2026-11-05 with all nine resource limits explicitly unlimited, no expiry and any client IP. Their tenant/project limits were also removed so shared rate/concurrency caps do not override the new Keys. Existing Key policies remain unchanged. Each new Key can discover all 45 published models and use all 16 business scopes; content remains owned by its creating Key and Admin authentication is separate.

Use `http://43.165.167.179:39443/v1` with `Authorization: Bearer YOUR_API_KEY`, discover models, inspect `usage`, upload required assets, submit `/v1/jobs`, then poll/download using the same Key. Frozen Workflow specifications and device scheduling still determine valid requests and runtime capacity. Eighteen live HTTP checks verify identity, discovery, policy and separation; no new GPU generation or host reboot was performed. Raw credentials are delivered privately and are absent from this repository.
