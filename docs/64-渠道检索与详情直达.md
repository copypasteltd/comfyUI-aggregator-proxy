# 64 · 渠道检索与详情直达

2026-10-24，第 64 增量。本地实现、真实 PG 查询、浏览器及精确候选安装验证通过；完整首版、原五类及 ComfyUI Workflow 音频范围不变。

## 需求和兼容边界

文档 07 明确要求渠道名称/地址可检索、列表分页、渠道详情可直达。当前页面只有分页，不能按名称或地址查找，详情抽屉也不能从队列/告警定位。本轮复用已有渠道列表、详情、队列及清单接口，补齐上述实际管理流程。管理身份及 channels:read/queues:read 等既有权限不变；业务 Key、Worker 与网关身份不能进入。

GET /admin/api/v1/channels 的查询在 contracts/admin-channel-query.schema.json 冻结：page 默认 1，范围 1～10,000；可选 q（1～128 字符）、channel_id、tenant_id、project_id、node_id、status。所有提供的条件取交集。q 在名称或 ComfyUI Base URL 中进行不区分大小写的字面子串匹配，百分号、下划线和反斜杠不作为通配符；不搜索凭证、历史配置或客户任务。q 不接受首尾空白及控制字符，页面提交时先 trim；各 ID 仅接受对应公开前缀和 32 位小写十六进制。未知字段拒绝。HTTP 页码仅接受整数形式，不把小数、布尔值或科学计数法转换成合法页码。

status 可为 enabled、disabled、draining、deleted。前三者仅匹配未删除登记；enabled/disabled 按启停事实，draining 按排空事实，启用与排空可同时成立。未提供状态仍返回全部登记（包括历史已删除项），保留原 API 行为；页面明确标注“全部状态（含删除）”。不存在或相互不匹配的合法 ID 返回空页，不把无匹配当作鉴权失败。结果沿用 data/page/has_more，每页 50、最多读取 51 条，按 created_at 降序及 id 升序稳定分页。没有新增总数、跨请求历史快照或预测等待值。

列表在只读事务执行，5 秒语句、1 秒锁预算；数据库异常以固定脱敏错误返回，失败不伪装为空结果。无新增表、索引或迁移，head 保持 0a7d9b4e2136。20 台设备规模下先保留有界子串查询，生产数据量/执行计划仍须实测，不引入未经验证的全文索引。

## 图形流程与详情

页面提供名称/地址、项目、节点、状态及精确渠道 ID 条件，显式应用/重置；编辑草稿不立即改变已应用筛选。换条件回到第 1 页并清空不匹配快照，同条件读取失败可保留标明读取时间的最后成功结果。列表与节点选项独立读取，节点读取失败不阻断渠道列表。每次读取有 10 秒总预算，无新增后台轮询；隐藏、离页、注销和后续读取取消旧请求、计时器，迟到响应不得覆盖新筛选或当前详情。恢复可见先核对管理会话，再刷新当前条件。

项目选择器复用已有分页目录：默认启用项目，只在本只读筛选中提供“查看停用项目”切换，通过既有 enabled=false 查询选择历史范围。创建/编辑流程保持原默认，不因此允许向停用项目写入；历史选择不改变会话默认创建项目。目录读取同样有 10 秒预算，切换搜索/页码时清除不匹配选项，隐藏或卸载释放读取与计时器。模式切换和错误提示位于选择器外，空结果在弹出框内明确展示，并允许修改/清空搜索恢复选择。

渠道详情使用站内 /channels?channel=ch_…，URL 只含公开渠道 ID，不写地址、凭证、草稿或搜索词。支持直接打开、切换目标、关闭和浏览器返回；无效参数不发请求，合法但不存在的 ID 显示明确错误。GET /channels/{identifier} 现有返回用强类型 DTO 描述，补充展示地址、节点、GPU、期望/应用/验证版本和最近 50 条配置历史的安全信息；凭证仅展示是否配置。

详情配置、队列和清单分别来自权威接口，独立失败与观测时间需分别表达，不冒充同一数据库快照。没有 queues:read 时不请求队列；历史已删除项允许查看保留的登记与配置历史，但不再请求现场队列/清单或提供现场管理动作。当前状态与过去版本不混为已应用事实；批准运行仍使用原版本、证据和冲突检查。列表和关联资源使用同一个安全详情入口，查看不会触发探测、同步或生成。
