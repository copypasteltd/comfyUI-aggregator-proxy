# 模型文件目录实现约定

日期：2026-10-22；设计基线 v0.4。细化 [工作流产品化](./04-工作流产品化规范.md) 和 [图形 Admin](./07-Admin可视化管理后台.md) 中的底层模型文件管理要求。

模型文件目录与公开模型别名分别管理。目录登记租户、项目、显示名称、类别、ComfyUI models 目录内的规范相对路径、SHA-256 和字节数；登记不表示文件已在任何设备存在。设备仍需通过冻结依赖校验与真实运行验证才可承接生成。

`GET/POST /admin/api/v1/model-artifacts` 和 `PATCH/DELETE /admin/api/v1/model-artifacts/{id}` 分别要求 `models:read/models:write`。写入检查管理会话、CSRF 和幂等键；更新、删除同时要求 `If-Match`。每页 50 条，名称和启停可改，内容标识（路径、类别、哈希、字节数）不可原位修改；新文件内容登记为新记录，旧冻结发布继续使用原始依赖。

相对路径拒绝绝对路径、父目录、反斜线、盘符、空段、控制字符、Windows 保留设备名以及以空格/点结尾的组件。路径只用作已授权目录内的声明，不触发下载、安装、重命名或删除 Windows 文件，不接受任意 shell。

同项目仍有效的相同路径（忽略大小写）与哈希不能重复登记。删除为目录逻辑归档，不删除真实权重；同项目冻结 Workflow 仍引用该内容哈希时返回 409 并提示引用。普通停用不修改既有冻结发布或在途任务。历史兼容行缺少摘要时明确展示“未完整登记”，不能自动补造哈希或证明设备可用。

数据库保存目录版本与删除时间；审计保存管理主体、动作与版本，不记录渠道凭证。首版验证至少覆盖并发重复登记、版本冲突、幂等删除、同项目冻结引用保护、跨项目引用隔离和路径拒绝，并通过浏览器实际创建、编辑、归档一条合成登记。真实文件扫描和设备运行证据仍单独验收。

本机扫描与受控登记的增量实现见 [45](./45-渠道模型清单与受控登记.md)。扫描结果按项目对照有效登记的相对路径和大小，哈希比较必须等待实际文件检查；浏览器不能提交证明字段或扩大项目范围。只在服务器保存的当前 boot/revision、未过期目录和成功检查证据上生成目录记录；相同有效路径/哈希并发登记复用原项，不恢复停用状态。原生 Windows 文件与 HTTP/PG 合成验证不替代真实权重、外部路径及设备运行验收。
