# 09 · 模型适配样本与用户流程

## 1. 样本的用途

以下 11 个别名来自已经保存的公开模型说明，配合当前 DTO 完成了 101 项离线检查，**不是本次重新查询的在线目录**。正式画布必须从用户当前 Key 的 `/v1/models` 与 `/v1/capabilities` 动态构建界面，不能把此表硬编码成“当前全部在线模型”。

## 2. 用户在融合版的预期操作

| 步骤 | 用户操作 | 系统行为 | 可见结果 |
| --- | --- | --- | --- |
| U-01 | 打开高位服务的 `/studio/`，选择或新增“ComfyUI 中转”连接 | 规范化源站，用户自行输入业务 Key；明确本机保存选择，不从 URL 导入 Key | 连接状态和权限摘要；不是 Admin 登录 |
| U-02 | 打开模型选择 | 读取当前授权目录、注释、任务类型、输入槽位和合法 preset | 只显示获准且可解释的能力；未知版本不能提交 |
| U-03 | 选择模型/规格，拖入参考素材 | 依 Schema 显示字段；上传到业务素材接口并记录稳定上传意图 | 每张图的角色、顺序、上传状态和缺项清楚可见 |
| U-04 | 点击生成 | 校验表单/身份，持久化独立日志后才提交稳定幂等请求 | 节点进入真实排队/执行状态，可查看 job ID |
| U-05 | 离开页面或刷新后回来 | 读取本机日志、查询原任务；未知提交按原意图恢复 | 原任务继续，不生成第二个任务 |
| U-06 | 任务成功 | 读取受权元数据与文件，验证字节/hash，提交本地保存和节点关联 | 图片、视频、音频或 GLB 结果；显示真实规格和是否已存本机 |
| U-07 | 保存/导出或继续引用结果 | 仅使用当前身份能读取的原内容，复用已校验本地文件；必要时按模型上传输入 | 下载失败可重读原产物，过期和空间不足有明确提示 |
| U-08 | 管理者查看设备/任务 | 通过独立 Admin 会话访问现有后台，不借业务 Key 提权 | 全局/分渠道队列、发布/Key、池与回收状态分别显示 |

此流程是待开发产品行为，当前原版不能完整执行上述步骤。界面使用青柠主题，手机采用可折叠侧栏/抽屉，不能只把桌面画布缩小后宣称移动可用。

普通用户不需要安装 Node、运行 npx、连接 Codex 插件或本地 Agent。托管版将这些原版高级入口移出默认创作流程并关闭自动连接；主流程只需要配置获准的 API 连接、选模型、准备输入、生成和保存。文本助手若启用，则另配 Sub2API，不把其 Key 与媒体业务 Key 混用。

模型出现在授权目录中不等于设备立即空闲；个人任务界面只使用当前 Key 可见的实际状态。设备在线详情、全局/分渠道队列和资源维护由 Admin 展示，不为业务 Key 假造全局排位、百分比或准确完成时间。

## 3. 适配器输出示例

以下为本地快照中存在的请求结构，用于审查参数转换；示例 asset ID 是占位符，不可原样提交。实时能力变更后以新目录和 Schema 为准。所有创建走 `POST /v1/jobs`，使用业务 Bearer、稳定 `Idempotency-Key`，以及待服务端实现的 expected-release 前置头；后者当前尚不能提供强制保证。

单图编辑不能把源图塞进数量为零的 references，也不能省略源图：

```json
{
  "model": "comfy-3080-image-edit-wai",
  "task_type": "image_to_image",
  "input": {
    "prompt": "在参考构图上调整为柔和日光，保留主体。",
    "source_image": {"asset_id": "asset_REPLACE_WITH_UPLOADED_ID"}
  },
  "parameters": {"n": 1, "size": "720x1080", "quality": "standard", "seed": 42}
}
```

多参考视频显式保留两张图的顺序和角色，不能转换为单图 first_frame：

```json
{
  "model": "comfy-4090-video-h3-refs",
  "task_type": "references_to_video",
  "input": {
    "prompt": "保持主体身份，镜头缓慢前移，运动自然。",
    "references": [
      {"asset_id": "asset_REPLACE_WITH_UPLOADED_ID_1", "role": "reference_0"},
      {"asset_id": "asset_REPLACE_WITH_UPLOADED_ID_2", "role": "reference_1"}
    ]
  },
  "parameters": {"n": 1, "size": "720x1080", "quality": "standard", "seconds": 5.167, "seed": 42}
}
```

Workflow 音频不走 `/audio/speech`，不把输出采样率或格式整包带入生成参数：

```json
{
  "model": "comfy-3080-music-yue2",
  "task_type": "text_to_audio",
  "input": {"prompt": "Gentle chamber music with warm strings and a soft piano melody."},
  "parameters": {"n": 1, "quality": "standard", "seconds": 30.0, "seed": 42}
}
```

3D 仅提供这个发布允许的输入，不能沿用图片/视频表单的隐藏 size 或 prompt：

```json
{
  "model": "comfy-3080-3d-trellis2",
  "task_type": "image_to_3d",
  "input": {"source_image": {"asset_id": "asset_REPLACE_WITH_UPLOADED_ID"}},
  "parameters": {"n": 1, "quality": "standard", "seed": 42}
}
```

## 4. 任务和文件怎样交付

收到创建响应后记录 JSON 中的 job ID；不依赖浏览器未暴露的 Location 头。服务任务状态为权威，客户端的“查询中/暂停/保存失败”另存。成功时读取 artifacts 的 content ID，从固定 `/v1/content/{id}` 获取公开元数据，再从固定 `/download` 受鉴权下载。

普通 `<img src>` / `<video src>` 无法自动携带业务 Bearer，因此下载后提供已验证的本地 Blob/持久存储引用，并按节点生命周期释放 Object URL。不能把业务 Key 放进播放或下载 URL。GLB 首先保证完整原件保存和可解释结果卡，三维交互预览及手机大文件能力另行验收。

云端文件成功后八小时到期，本地文件不随它一同删除。任务完成但本地保存失败时必须显示“远端已完成，尚未存本机”，不能显示“失败后自动重试生成”。可靠恢复、发布竞态和故障处理的完整规则以 [07](07-融合实现契约与故障恢复.md) 为准。
