# 18 · Admin 界面实现约定

适用于首版 Vue 管理界面，沿用文档07/13的权限、状态和验收约束。本文记录实现方向，不代表全部页面已经完成。

界面采用高密度运维控制台：固定侧栏、任务状态概览、物理GPU占用区、可筛选表格和编辑抽屉。首页直接呈现队列与设备；不使用营销首屏、演示统计或模拟成功消息。所有数字来自管理API；请求失败保留最后快照并注明失效时间，尚未收到数据时显示未知。

视觉基线为浅灰背景 `#f3f6f8`、深蓝导航 `#10293a`、青色操作 `#087e8b`、铜色提示 `#bf5e31`、绿色健康 `#268162`、红色异常 `#bb3b47`。标题使用本地 Bahnschrift/微软雅黑，正文使用系统中文字体，ID与计数使用 Cascadia Mono/等宽回退；不依赖外部字体服务。标识性区域是按物理GPU分组的占用展示，多渠道共享一张卡时不重复计算容量。

交互规则：

- 登录凭据仅提交到管理会话接口；业务Key不进入管理登录流程。Cookie始终Secure/HttpOnly；CSRF在内存中，刷新后通过当前会话恢复。
- 权限决定入口和按钮是否可用，后端仍逐次授权。操作员不显示Key管理与敏感内容入口。
- 渠道分别展示期望、已应用和已验证版本；创建后等待Worker执行，提交管理操作不显示为探测/同步已完成。
- Key密钥只在创建或轮换成功的当前抽屉中显示一次，关闭即清空，不写localStorage、日志或URL。重放响应没有密钥时，引导另行轮换。
- 修改使用ETag/If-Match与管理幂等键；冲突保留用户输入，刷新后重新比较。停用、删除、轮换等动作解释具体影响并明确确认。
- SSE用于通知重新取快照；连接成功后取一致快照，查询期间收到通知则在完成后再取一次。每5秒安全轮询；页面隐藏停止连接与轮询，恢复时先校验会话。
- 全局未分配队列与各渠道共享候选分列，不能相加为总量。过期15秒的设备观测显示未知，不能填零。
- 页面支持键盘焦点、中文可访问名称、清晰错误提示和减少动画；窄屏表格可横向滚动，不裁掉关键操作。

采用frontend-design与ui-ux-pro-max指导。设计检索返回的营销首屏、玻璃背景和远程字体不适合当前运维任务，使用上述实际操作布局。浏览器验收遵循AGENTS.md：只关闭本次创建的页面、上下文和浏览器，释放不用的资源。

## 队列筛选与刷新约束增量

[47](./47-队列筛选与实时负载验收.md) 冻结公共筛选栏和刷新行为：草稿表单只有显式应用才改变轮询；租户/项目变更清理不兼容子条件，按名称分页拉取的选项只含安全 value/label。最多缓存两页选项；隐藏、卸载时中止选项请求。切筛选/分页中止旧列表请求并清除不匹配快照；同条件读取失败保留最后成功数据并提示错误。

总览使用 SSE 失效通知和 5 秒轮询，任务页 5 秒轮询。共用刷新模块处理合并、取消和旧结果防覆盖；隐藏页关闭 SSE、定时器与在途读取，恢复先校验会话，退出清理。后端时间为 UTC 秒，日期组件按本地时区输入转换；界面明确结束时间不含，不展示预测 ETA。桌面和 390px 页面检查通过。

## 内容目录与媒体释放增量

[48](./48-内容检索标签与受控预览.md) 使用独立内容筛选栏：父范围变化清空不兼容子条件，选项按名称/50 条分页、最多缓存两页；草稿显式应用才改变目录，切条件/分页中止旧读取，页隐藏或卸载中止列表、详情和选项，恢复先验证会话。显示服务端生命周期与查询时间，不把本地时钟推断作为可用证明。

标签表单最多 16 项，规范化为 NFC 并检查长度、控制字符和重复；保存携带当前版本及固定请求体对应的幂等键。提交已成功而响应丢失时复用同键重试，409 保留草稿并要求显式重新加载/核对；不自动覆盖另一个管理员的版本。

只在主动预览后设置固定同源 src；图片不预下载，视频 controls/preload=none/不自动播放，不使用内存 Blob 保存媒体。关闭、切换条目、隐藏、退出及 before-unmount 暂停视频、移除 src、调用 load 释放；图片节点同步卸载。恢复可见不自动重新加载媒体。权限不足隐藏对应标签保存和敏感输入预览/下载控件；后端每次独立校验。390px 允许表格自身滚动，页面不横向溢出。
