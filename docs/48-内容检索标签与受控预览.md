# 第 48 增量：内容检索、标签与受控预览

日期：2026-10-23。对应 ADMIN-14、KEY-09/10、DEV-14/15/17/18/22/28/32、WP-03/08/10/13。本增量已通过下述本地原生验证，完整首版仍在开发；不缩减五类能力、真实资源或完整首版出口。

## 1. 管理目录检索

`GET /admin/api/v1/content` 保持独立管理会话和 `content:read`，补充统一查询契约：kind=input/output、租户、项目、创建逻辑 Key、关联任务、冻结模型别名、Workflow/不可变发布、单个标签、媒体类 image/video、生命周期、创建时间范围和页码。条件取交集，每页 50 条、页码 1～10000；响应返回 snapshot_at 与有效 filters。创建时间筛选内容条目的创建时间，UTC Unix 秒，from 包含、before 不含；边界 0～4102444800，同时指定时 from 必须小于 before。

产物按自己的 job 关联；输入素材通过持久 job_asset_references 和同归属任务 EXISTS 检索，未使用的素材不匹配任务/模型/Workflow 条件。多个引用只返回一个素材。模型与 Workflow 按历史任务冻结版本匹配，不跟随当前公开路由。标签精确、区分大小写匹配；标签和模型名不解释成 SQL 通配符。租户/项目/Key 条件筛选内容创建归属，不能被关联任务或标签改写。公共业务目录和 Key 内容授权保持独立，管理标签不授予共享权限。

生命周期优先级：reclaimed（对象已回收）、pending_reclaim（条目或对象请求删除）、expired（对象保留期已到）、unverified（对象尚未验证/未确定不可变版本）、available。状态由服务端在同一只读可重复读快照采样，不把未验证条目显示为可用。下载/预览每次重新校验当前生命周期，不信任旧列表状态。

`GET /admin/api/v1/content/filter-options` 使用 content:read，kind=tenant/project/key/model/workflow/release，名称查询最多 128 字符、每页 50 条、最大页码 10000。只返回 value/label 与分页；不返回 Key verifier、密文、Workflow 图、渠道地址、提示词或对象路径。固定静态路径必须先于 content/{identifier} 注册。

## 2. 标签与并发编辑

Asset 与 Artifact 各增加 tags、metadata_revision、metadata_updated_at；迁移后旧条目默认空标签、revision=1、updated_at=null。一个条目最多 16 个标签，每个 1～64 字符、NFC 规范形式、无首尾空白和 C0/C1 控制字符，不允许重复；标签顺序保留，不隐式折叠大小写。数据库约束标签数组及数量、正 revision。新增 GIN 标签索引与输入目录的归属/创建时间索引；先备份验证再迁移，迁移后做模型差异和恢复演练。

`PATCH /admin/api/v1/content/{identifier}` 只接受 expected_revision 与完整替换 tags，支持空数组清空。新增独立管理权限 content:manage，默认只赋予现有 administrator，其他角色不自动获得内容权限；业务 Key/Worker/网关身份不能调用。要求 CSRF、Idempotency-Key 与匹配的 If-Match；同键同体回放，异体冲突，并发旧 revision 返回 409。对条目行加锁后检查版本，标签修改和审计同事务提交。标签修改不改变素材、归属、保留期、共享授权、下载状态或 GPU/任务状态，过期/回收条目仍可整理标签。审计只记 revision/数量，不复制自由标签文本到日志。

管理内容视图补充 tags、metadata_revision、metadata_updated_at、status、preview_supported。新增字段对旧缓存/调用方保持可缺省；管理目录的新响应保证完整投影。业务内容元数据不因本轮标签管理扩大披露字段。

## 3. 主动预览

新增 `GET/HEAD /admin/api/v1/content/{identifier}/preview`，与管理下载相同的 content:download 权限；输入素材额外要求 content:sensitive。只支持已验证且可用的 image/png、image/jpeg、image/webp、video/mp4、video/webm，以固定同源地址直接流式传输，保留 HEAD/Range/416 语义。服务端在打开对象流前校验 MIME 白名单，不预览 HTML/SVG/任意文本；Content-Disposition 为固定安全 ID 的 inline，Cache-Control 为 private,no-store，禁止 MIME 嗅探和把对象存储地址透传给浏览器。

界面默认只加载元数据；用户点击预览才设置 img/video 的同源 src。视频 preload=none、controls，不把视频下载成内存 Blob、不自动播放。关闭抽屉、切换对象/标签页、隐藏页面、退出或卸载时暂停视频、移除 src 并释放播放器/图片；恢复可见先校验会话，预览须重新点击。预览失败显示可理解的读取/权限/到期提示，不泄露对象路径或内部错误。

## 4. 验收

真实 PostgreSQL 验证筛选交集、历史模型/Workflow、输入多引用去重、生命周期优先级、标签 GIN/约束、并发修订/幂等/删除竞态、跨 Key/项目/租户不被标签扩大授权。真实 HTTP 验证四身份和角色隔离、CSRF/If-Match、HEAD/Range/删除/到期/未验证/不允许 MIME 的预览，禁止预览绕过敏感输入校验。

浏览器检查名称筛选/显式应用/分页、标签修改冲突与回放、列表和详情、主动图片/视频预览、隐藏/切页/退出释放及 390px 布局。使用合成媒体、原生进程和独立数据库；不调用 Docker/WSL、不访问未授权真实资源，浏览器必须 finally 清理自身 context/browser。
