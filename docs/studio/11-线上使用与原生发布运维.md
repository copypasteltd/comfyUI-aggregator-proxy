## 访问与使用

画布入口：[http://43.165.167.179:39443/studio/](http://43.165.167.179:39443/studio/)。管理后台仍为同源 `/admin/`，业务 API 为 `/v1/`。服务使用普通 HTTP 高端口，域名反代由用户处理。CORS 允许任意 Origin，业务权限继续由 API Key 判定。

管理员在原 Admin 的 API Key 页面创建业务 Key，选择允许的模型、生成/读取/上传/下载权限和配额，再把一次显示的 Key 交给使用者。画布连接页填写服务源站 `http://43.165.167.179:39443` 与业务 Key；模型页读取该身份的实时目录、注释、合法规格和参考图要求。Key 不放 URL，不使用管理密码或 Worker 凭证代替。

新建画布后选择“新建创作”，选择模型和完整规格，填写提示词或要求的源图/参考槽位，明确提交一项任务。查看原任务状态；成功后载入校验后的文件。刷新或回到任务页继续查询原 ID。响应未知时“核对原提交”沿用同一请求及幂等键；停止本页等待与取消远程任务是两个操作。

GLB 以下载卡交付，不宣称已实现交互式三维编辑。音频来自 ComfyUI Workflow。首帧与多参考视频使用不同模型，不把缺少的参考自动忽略。未声明的尺寸不能自由混搭。服务端成功后八小时到期；浏览器本机副本和另存原件/ZIP 独立管理。

任务页可导出任务清单JSON；它与保存画布/原件的作品ZIP分别备份。导入时连接原服务/原Key，选择文件、检查预览并确认“仅导入记录”。导入不会生成、上传、覆盖画布或自动查询；已知任务须主动查询原ID后才能取消/读取产物，无ID的备份禁止补发。离线时可导出已保存身份的清单；文件不含Key，但提示词按原文保留，请妥善保管。[格式、事务与安全边界](13-任务清单备份与只读恢复.md)。

## 当前部署和回滚依据

132 的只读恢复扩展：任务未知或从备份恢复且无 ID 时，选择“只读核对原提交”，调用 `/v1/jobs/lookup`。只有本机原生、从未发送的 `prepared` 记录允许首次提交；找不到映射也不补发。服务通过 `X-Studio-Submission-Lookup: 1` 声明支持，旧服务应更新并重新连接。使用原 Key，不能静默换 Key 接管旧记录；详见 [核对契约](14-原提交只读核对与恢复.md)。

132 原生发布按“离线安装七包并校验 → 新生产数据库备份 → 后端固定版本切换 → 静态向前切换 → 公网与持久化复验”执行。`backend-prepare-1322` 和 `backend-promote-1322` 分别准备、发布，`backend-status-1322` 读取状态；静态使用 `static-upgrade-1322`（132.1清单修正后继续向前发布），保留 v3，禁止旧 UI 往返。准备阶段不切运行版本；后端发布会重启 API/Runner/GC，原 GPU Worker 不重启。数据库没有迁移，已有忙碌任务或资源占用会使前置检查拒绝切换。

## 原生发布规则

使用提交的锁在原生 Node/npm 构建；按当前构建与浏览器报告生成静态清单，对实际 dist 的每个文件核对摘要。`docs/tools/build_studio_static.py` 拒绝打包与已通过报告不一致的内容。工具中的已有发行ID和路径是本次部署记录，后续版本必须建立新的版本ID与回执，不能覆盖旧包。

云端静态目录为 `/opt/comfyui-aggregator/studio-releases/<release>/studio/`，`studio-current` 原子链接选择版本。后端发行目录与 `current` 独立选择。公共入口使用专用 `/usr/bin/nginx` 配置，避免覆盖服务器另一套 nginx；仅修改39443公共服务，39001其他应用和内部Worker入口保持原用途。

`/studio/` 及其深链回退到对应 index.html；JS、CSS、字体和Schema Worker使用正确MIME。主文档严格CSP；仅独立校验Worker允许Schema编译，Worker禁止网络连接。不要把Worker权限扩散到主文档。升级保留原IndexedDB和业务身份；遇到损坏/未知版本时保留记录，不清空数据作为修复。

当前132.2的浏览器数据库为v3；131.7的v2文档/引用事务继续保留，v3增加恢复行为保护，v1/v2旧客户端不能打开。须重载新版本，不能将静态指针回退当作本机数据降级，也不要删库“修复”。恢复记录首次鉴权查询前不信任备份中的revision和终态。若旧页继续编辑旧副本，新页拒绝自动覆盖，先导出未保存内容再人工合并。保存失败可显式重试；跨页revision冲突先导出再重新载入。普通image/file自动回收暂停；[文档保存机制](12-本机引用事务与保存失败恢复.md)与[清单恢复机制](13-任务清单备份与只读恢复.md)分别适用。

后端切换前检查数据库归档、健康、任务/GPU持有和原Worker状态；需要变更数据库时另行遵循原项目迁移规则，本增量没有迁移。切换后核对健康、契约头、模型/能力目录和任务/内容记录。实际回滚测试记录每一步的版本及结果，不用一次HTTP200代替整个验收。

本地部署工具读取忽略目录中的私有连接资料，固定SSH主机指纹，不内嵌密码/Key。`studio_ship.py` 和固定主机脚本是本次可审阅运维记录，不是跨服务器的一键安装器。临时验收Key在验收结束停用；不写入README、截图、录屏或发行包。
