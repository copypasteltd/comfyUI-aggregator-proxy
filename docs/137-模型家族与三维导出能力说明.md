## 单人和双人语音

一个只有 `speaker_1` 参考录音槽位的 SoulX 型号，因测试台词同时使用 `[S1]` 和 `[S2]` 而被其原生解析器拒绝。修正测试为只使用实际声明的说话者，保留原请求和失败任务，不改变冻结图或转移批准。

语音名称现在区分单人/双人。调用备注只列出该版本实际有参考录音槽位的说话者标记：只有 `speaker_1` 时使用 `[S1]`，只有 `speaker_2` 时使用 `[S2]`，双人版本才同时声明两者。逐行台词不能引用没有提供参考声音的角色；参考转写必须对应录音原话，生成台词另填。

Single-speaker models advertise only the label connected to their declared reference recording. Use both labels only with a model that declares both speaker slots. Reference transcripts describe the recorded words; dialogue contains the new lines to generate.
