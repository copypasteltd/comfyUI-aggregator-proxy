# Media Gen Skill 1.5.1

原生面板现在可查看设备的完整共享 Workflows 目录，包括中文文件夹和空文件夹。原 Key 私有工作流保留在 `@personal`，设置、自动保存和任务/文件归属继续隔离。保存目录不代表流程已具备完整模型或节点，执行前仍须检查依赖。

`save-workflow`、`delete-workflow` 默认操作个人目录；明确加 `--shared --operation-file PRIVATE_FILE` 才修改源设备。`move-workflow` 支持共享流程重命名，`resume-workflow` 使用原持久意图核对丢失回执。共享修改需要获准 Key、活跃设备独占和 CSRF，会影响源机及其他获准操作者；不会执行图、安装节点或下载权重。

The native panel exposes the complete live source Workflows tree. Existing private files move to the `@personal` virtual mount without data loss; browser settings, autosave, tasks and generated file ownership remain isolated. Missing dependencies remain visible and must be checked before execution.

Personal save/delete remain the CLI default. Explicit `--shared --operation-file PRIVATE_FILE` saves/deletes an actual source file; `move-workflow` renames a shared graph. `resume-workflow` preserves the original durable identity after a lost response. Source modifications require granted native access, an active device reservation and CSRF, and affect the original device. Saving does not execute a graph.

Both clients default to https://gen.sub2share.xyz. The ZIP and self-contained `skill.md` include both references and standard-library Python 3.10+ clients. The source tag publishes immutable GitHub assets; the fixed online `/skill.md` is separately deployed and verified. Historical versions are retained.

1.5.0 was a tagged source candidate whose release workflow lacked its notes file; it was not deployed as the current online Skill. 1.5.1 supplies the complete release inputs while retaining that tag and failure record. Validation and production evidence: [topic 150](../../150-原生工作流完整目录与源站操作修复.md).
