# Media Gen Skill 1.3.0 · Named multimodal inputs

增加命名图片、视频、音频和 GLB 输入，工作流文本槽及兼容父任务：`--media SLOT=FILE`、`--text NAME=TEXT`、`--text-file NAME=FILE`、`--parent-job JOB_ID`。上传使用有界流式 multipart，可指定稳定幂等键；不把示例占位素材、参考台词或生成对话自动提交。必填、重复、未声明的槽位在本地明确报错，服务端仍独立检查所有权、格式、规格与配额。

Adds named image/video/audio/GLB inputs, declared workflow text fields and compatible parent jobs. Uploads stream in bounded multipart chunks with an optional stable idempotency key. Missing or duplicate fields fail explicitly; examples are not substituted for actual inputs. The server independently enforces ownership, formats, specifications and quotas.

先使用实时 `/v1/models/{alias}` 的 usage；只使用其声明的槽位和冻结规格。参考录音转写与生成对话分别填写。声音策略随工作流冻结，续拍使用同一 Key 的兼容成功父任务，输出与上下文按八小时保留规则处理。候选草稿不等于可调用模型。已有图像、音频、视频、GLB、提交恢复与校验下载继续支持。

Discover the live usage schema first. Pair transcripts with the actual reference recordings and provide generated dialogue separately. Audio policy is frozen by the workflow. Continuation requires a compatible successful parent owned by the same Key. Existing asynchronous submission, exact-request recovery and verified downloads remain supported; outputs/context retain the eight-hour policy.
