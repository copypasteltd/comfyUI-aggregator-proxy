# 59 · S3 版本与范围交付校验

2026-10-24。第 59 增量；先冻结本文再修改实现。本地实现、分层验证与候选安装已通过；真实私有 S3 和生产交付仍未验收。

## 问题与范围

现有 `S3Store.read` 将 `VersionId` 和 `Range` 发给 SDK，却直接转发响应体，没有核对返回版本、状态、范围或长度。隔离故障复现中，请求指定版本的 3 字节范围却收到错误版本的 25 字节全文；旧实现把它完整返回。证据为 [修复前复现](./evidence/2026-10-24/s3-boundary-before-fix.json)，不涉及真实桶、客户文件或凭证。

图片、视频及 ComfyUI Workflow 音频共用此存储端口，本增量修复该交付边界。保持业务/管理/Worker/网关身份和逐次内容授权；不新增公开端点、JSON 字段、DDL、Workflow 类型或价格规则。适用 DEV-18/19/25/26/29/31/32、WP-03/05/13/14。HTTP 标准依据为 [AWS GetObject](https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetObject.html) 与 [DeleteObject 的指定版本响应](https://docs.aws.amazon.com/AmazonS3/latest/API/API_DeleteObject.html)；本项目支持已有通用版本化桶，未声明支持 directory bucket。

## 固定行为

1. 所有 S3 对象操作继续验证受控相对 key；读、删、签名要求非空、非 `null`、最多 1024 字符且无控制字符的不可变版本 ID。版本是服务端不透明字符串，不假定为本地存储的 32 位十六进制。非法参数在访问 SDK 前拒绝。
2. 读取只接受非负整数 `start <= end`，布尔值不算整数。GET 明确携带原版本及单一闭区间 Range。响应必须为 206，返回版本与请求严格相等，Content-Range 为相同起止且总大小大于 end，Content-Length 等于 `end-start+1`。缺失、通配总长或错配一律拒绝，在转发任何字节前关闭响应。
3. 每次读取最多 1 MiB，且不超过剩余字节预算。提前 EOF、超过预算或结束后仍有额外字节均失败。已开始 HTTP 响应后发生的 I/O 错误只能中断连接，不能承诺将已发送状态改成 JSON 503。调用方关闭迭代器必须释放响应体；不将流中断当作成功完整交付。
4. put 仍采用 8 MiB 内存阈值的有界暂存，执行最大大小检查和流式 SHA-256。返回有效不可变版本后，使用上述严格读路径回读并验证全部字节摘要；错误版本/范围/截断/摘要不符不得返回 StoredObject，不得发布终态。ETag 不代替 SHA-256。
5. delete 只发送明确版本，并核对 204 与版本回显；响应不确定时抛出错误，让现有 GC 保留待确认状态。签名 URL 使用明确原版本，时长必须为正整数并至多 900 秒；原有上层 Key/对象到期交集不变。
6. S3 SDK/网络错误归一为固定 `storage_unavailable`，不附带端点、桶/key、SDK 原文或签名 URL。协议不一致为 `storage_response_invalid`，提前 EOF 为 `object_truncated`；均为领域 503。已有 `storage_versioning_required`、`public_bucket_denied`、`bucket_privacy_unverified`、`object_hash_mismatch` 保留。关闭响应失败不覆盖主要业务错误或泄露 SDK 信息。

API 契约版本维持 0.5.0，Worker 协议维持 0.4.0。此次收紧的是存储响应完整性；不完整的兼容服务会被明确拒绝，不能通过放宽验证来宣称兼容。无迁移需求，服务升级仍先停止本项目开发 API/Runner/GC，再修改和验证；原生 PostgreSQL 保留。

## 验证出口

- 单元故障注入：错误/缺失版本、状态、范围、长度；零/负/布尔/逆序参数；提前 EOF、超长响应、SDK/网络异常；正常完成、显式关闭和错误路径资源释放；put 大小/摘要/版本校验、精确删除与签名时限。
- 原生回环 HTTP：实际 boto3/botocore 经签名请求访问明确标记的合成 S3 协议端，验证版本/Range 请求、真实网络流、响应异常和连接关闭。它不是真实 S3 服务，不替代真实桶/IAM/存储耐久性验收。
- 真实 PostgreSQL/HTTP 内容授权回归、完整 Python/静态检查、当前候选构建与精确离线安装。与变更无关的历史图形/Go/负载证据需按源文件及二进制摘要核对后才能沿用，不能计为本轮新运行。
- 证据保留修复前复现和任何失败；所有合成服务、测试库、媒体、凭证与浏览器按 finally 释放。不使用 Docker、WSL、虚拟机或子代理，不自动安装 ComfyUI 节点或模型。

## 完整交付边界

真实私有 S3 的版本/IAM/撤销/大文件吞吐，生产对象与主密钥联合恢复、真实 Windows/ComfyUI、六类实际 Workflow、真实 Redis、公网/Linux/系统服务与 10/20 台设备仍分别验收。当前缺少用户后续提供的真实资源，不将协议端或开发候选当作这些出口已完成。
